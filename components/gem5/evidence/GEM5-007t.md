# GEM5-007t 集成回归证据

## 范围与 oracle

- `tests/gem5/programs.yaml` 对 `tests/e2e/*.{c,s}` 做集合闭包；可运行项逐项记录
  独立退出期望，非运行项逐项记录排除理由。删去一条分类记录时驱动以 rc=2
  报 `E2E inventory is not closed`。
- E2E 期望来自自校验程序、源码手算或既有独立任务证据；Embench 期望来自
  `verify_benchmark`，不读取 QEMU 输出。Embench 正确性档仅把 warmup 和计时
  重复降到最小，保留算法及自校验，不用于性能结论。
- JSON 报告逐例保存构建命令、gem5 命令自身退出码、退出事件、guest 退出码、
  最终 IP/模式/CFX 和字段差分；超时、非 semihosting 退出或缺失退出码均失败。

  重新生成后 rc=0。
- `--inject-result`：首例期望 42→43，实际 42，驱动 rc=1。
- `--inject-drop-exit`：首例模拟丢失 guest exit，实际记为 `null`，驱动 rc=1。

`.work/**` 引用、picolibc 触发 LLVM 后端缺口，以及 `test-m6` LLVM
