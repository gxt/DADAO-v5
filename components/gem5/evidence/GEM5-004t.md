# GEM5-004t 验收证据：标量指令与返回地址栈

日期：2026-10-12。执行分支：`GEM5-004t`。gem5 组件基线：
`c8222cc67a399bfc01e8658dd14b30d5bfd634f9`；定制提交：
`953cfcfd6b230031a8a2227861ac3a763886beb3`。

## 实现范围

- 实现当前有 active 向量的 151 个 M1 指令 ID：64/32/16/8 位整数与地址运算、RD/RB/RA 单寄存器和块访存、条件分支与跳转、`call`/`ret`、RegRAS/MemRAS 以及 `swym`。
- 地址按 48 位回绕，数据按大端访问；覆盖 `CFXMEM`、`MALIGN`、`ILLI`、`UNDI`、`IALIGN`、`RASOF`、`RASUF`。
- `ra0` 的 SBZ 位在寄存器搬移、访存、fixture 写接口和 RAS 更新路径统一清零。
- `rb0` 保留完整 64 位控制流结果，PC/NPC 使用低 48 位；显式控制流与顺序执行分别处理，覆盖顺序回绕、not-taken 回绕、目标等于下一条及自环。
- 块 load 在全部读取成功后提交寄存器；块 store 先探测全部地址，写入失败时回滚，避免精确异常留下部分状态。

## 独立审阅

首次审阅拒绝四项：缺少窄位宽 M1 与 `swym`、`rb0` 高 16 位丢失、块
store 后续 fault 留下前缀写入、`ra0` SBZ 未统一清零。修复后第二次审阅
确认后三项和窄位宽实现正确，但发现顺序/not-taken 的 48 位回绕仍会丢失
`rb0` 进位。最终以 `PCState::explicitBranch` 区分显式控制流，补入顺序
`swym` 回绕反例；复审针对顺序、not-taken、目标等于下一条和自环均通过，
最终判决 `Accepted`。
