# SimRISC LLVM 后端优化工作报告（LLVM-130～133）

## 摘要

本 PR 汇集一轮 SimRISC LLVM 后端优化：先盘点 IR 到汇编的机会，再交付三项严格受限的 target-local codegen 改进。所有改动复用既有 ISA 指令与 ABI；不修改 `spec/`、`contracts/`、QEMU、通用 LLVM pass 或浮点收缩边界。

“减少”均指已断言的目标汇编冗余指令，不能替代端到端性能测量。

## 机会盘点

盘点覆盖 TTI/target hook、标量与常量选择、浮点边界、访存/复制/控制流和 post-RA 合并。FMA、min/max、取整、分类、缩放、饱和转换及 `ldm`/`stm` 已有实现，未重复计为新优化。盘点本身不改变后端实现；它只确定后续可验证的小范围候选。

## 64 位常量移位立即数选择

对 `i64` 的 `shl`、`lshr`、`ashr`，当编译期移位量在 `0 <= shamt < 64` 时，选择既有的 `shl.o`、`shr.uo`、`shr.so` 立即数形态。此前该路径会物化移位量并使用寄存器移位。

- 覆盖移位量 0、1、31、32、63 与变量移位；
- 变量移位保留寄存器形态；LLVM poison 的非法移位量不被构造或利用；
- Python 按 u64 截断及有符号右移独立派生期望值，QEMU 结果与之比对。

## 窄整数 canonical extension 折叠

SimRISC 窄整数指令可按符号或无符号方向把结果扩展到 64 位。对生产者与显式 `sext`/`zext` 方向完全一致的组合，后端选择正确的 `.s*`/`.u*` 变体，消除随后的 `ext.so`/`ext.uo`。

- 覆盖 i8、i16、i32 的 39 个精确组合：算术、带符号/无符号除余以及窄移位；
- `zext(ashr)`、`sext(lshr)` 与非目标生产者保留显式 extension；
- 保留窄 `sub 0, x` 的既有处理，避免改变 narrow-neg 语义。

## 循环指针 PHI 的 GPRB 保持

地址值在 lowering 后与普通 `i64` 共用位宽表示，循环 PHI 可能因丢失 bank 见证退回 GPRD，并在每轮地址消费前插入 `rd2rb`。本 PR 加入一个窄范围的 DADAO machine pass：仅处理入口已在 GPRB、单入口/单回边、无 call/inline asm 的直接 pointer PHI 与两段 GEP 形态。

该 pass 在寄存器分配前重建 GPRB PHI 和对应 RB 加法；普通 `i64`、`ptrtoint`/`inttoptr` 链、inline asm、跨调用、select 和多入边 PHI 都保持原有回退路径。它不改变全局 `i64` 寄存器类、ABI 或指针整数转换语义。

代表循环的 O2 汇编中，循环内 `rd2rb` 降为 0，未新增 spill/reload，并保留两条地址 `add.o`。六个非目标负例均未生成 GPRB PHI。

## 验证

- 新增三份 DADAO CodeGen lit，完整 CodeGen/MC 集合 151/151 通过；
- 每项有结构断言、独立 Python oracle 与 QEMU 运行期比对；循环指针用例覆盖 6 组结果；
- 注入错误的指令形态或 oracle 期望均可使检查失败，恢复后回绿；
- 组件 patch tree、patch index、ISA 覆盖和安装工具一致性均通过。

`LLVM_TOOLS_DIR` 现优先于 lit site configuration，使验证可明确选择刚重建的 `llc` 与 `FileCheck`，避免安装根陈旧造成误判。

## 边界与后续

本 PR 不改变普通 `fmul + fadd`、`llvm.fma` 或 `-ffp-contract=off` 的边界，也不声称整体程序性能提升。后续若要量化端到端收益，应在真实工作负载上测量动态指令数、热点和运行时间。
