# 测试体系 -- 资源与权限测试

**本册要点**

- arch 测的是资源访问与权限，不是单条指令的算术语义。
- 用状态矩阵覆盖：模式 × 资源 × 操作。
- 判据是现场（原因码 + 上下文），不是"程序非零退出"。
- 负例可机械枚举：保留编号、不存在寄存器、非法窗口、越权访问。
- 任务级按 `CFX=` 选单个资源，smoke 是代表集，全量跑全部资源。

## 1. arch 到底测什么？

**答：** 测"谁能访问什么、越权时发生什么"：陷入与退出、资源寄存器读写、各类掩码、异常原因、跨核与系统级资源。

- **访问路径**：寄存器读写、窗口访存、取指。
- **权限层次**：运行模式、资源掩码、地址转换权限。
- **异常形态**：原因码、现场保存、嵌套与重入。
- **资源类别**：监视器、地址转换、存储层次、执行资源、时间与设备。

## 2. 状态矩阵怎么建？

**答：** 三维：模式 × 资源 × 操作，每格给"期望成功或期望原因码"；先用等价类合并，再对边界单独测。

- **模式**：四种模式各有独立入口与能力集。
- **资源**：按编号分段，不同段归不同模式所有。
- **操作**：寄存器访问、窗口访存、陷入与退出。
- **合并**：同权限同行为的格合并，端点与越权单列。
- **缺口**：未覆盖的格登记理由。

## 3. 为什么断言现场而不是退出码？

**答：** 因为退出码只说明程序结束了，说明不了"该报的异常报了、原因对不对、现场保没保"。

- **现场内容**：原因码、返回地址、前一模式与掩码、待处理位。
- **典型缺陷**：原因码错；现场未保存导致返回错位；嵌套覆盖外层现场。
- **断言方式**：读现场并逐字段比对。
- **前提**：需要能读现场的手段。

## 4. 负例怎么枚举？

**答：** 四类机械生成：保留编号、不存在寄存器、非法窗口地址、越权访问；每类都有明确期望原因码。

- **保留编号**：访问未实现的资源 ⇒ 非法指令类原因。
- **不存在寄存器**：越界编号 ⇒ 寄存器不存在类原因。
- **非法窗口**：窗口外地址 ⇒ 窗口非法。
- **越权**：低权限访问高权限资源 ⇒ 权限不足。
- **价值**：负例便宜且容易发现"静默通过"。

## 5. 跨核、系统资源与中断怎么测？

**答：** 分开测：每核资源看隔离性，系统级资源看共享与仲裁；中断类要测"置位—分发—处理—清除"全链。

- **隔离性**：一个核的操作不应影响另一个核的本地状态。
- **共享资源**：访问顺序与仲裁由软件约定，需构造竞争场景。
- **中断链**：触发源 → 待处理位 → 分发 → 处理 → 清除。
- **电源**：关机/复位类操作的收尾顺序。
- **未判定**：单核环境无法测多核行为 ⇒ 记未判定。

## 6. 三级怎么分？

**答：** 任务级按 `CFX=` 选单个资源做定向验证，smoke 取每个资源的代表场景，全量跑全部资源与组合。

- **任务级**：`check-arch-smoke CFX=<资源>`，两分钟内。
- **smoke**：代表场景 + 四类负例。
- **全量**：全部资源、全部模式组合。
- **一层一列**：smoke 只在快速层列，全量只在全量层列。

## 背景知识

### 术语与概念

- **cfx**：按功能划分的核内资源单元。
- **原因码**：异常的分类标识。
- **现场**：异常发生时保存的架构状态。
- **targeted**：按单资源选跑。
- **per-hart / per-task / per-system**：每核私有 / 每任务（申请后使用） / 全系统共享。
- **待处理位**：中断或异常请求的挂起标记。

### 对照

**系统态测试形态**

- **内核自测**：在 guest 内核态断言异常与权限。
- **架构合规测试**：跨异常级别，需参考模型。
- **本设计**：状态矩阵 + 现场断言 + 负例枚举。
