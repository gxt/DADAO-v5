# 资源管理 -- 存储层次

**本册要点**

- 三个 cfx 分工：每核缓存（cache）、最后一级缓存（llc）、物理内存（pmem）。
- 缓存侧只有三件事：存在性、开关、维护命令（失效/回写）。
- 最后一级缓存跨核共享，因此是**全系统**资源。
- 物理内存管理最多描述 **64 个不连续区域**，重叠时编号小的优先。
- `pmem` 内还有一段 **64 KiB SRAM** 和一个 **DMA 引擎**：SRAM 可被普通访存读写，DMA 在 SRAM 与物理内存之间搬运。
- 维护次序固定：改页表 → 失效 TLB → 清缓存。

## 1. 每核缓存管什么？

**答：** 三组寄存器：存在性（只读）、开关（读写）、维护命令（只写）；维护命令负责失效指令缓存、失效数据缓存、回写数据缓存。

- **存在性**：硬件设置，指示哪类缓存存在。
- **开关**：复位值等于存在性，即"有的默认开"。
- **维护**：失效指令缓存、失效数据缓存、回写数据缓存。
- **粒度**：整类操作，不做单地址维护。
- **判据**：代码改动后是否需要清指令缓存。

## 2. 为什么开关的复位值等于存在性？

**答：** 因为"硬件有缓存"与"软件想用缓存"是两件事：复位时让存在的缓存默认开启，能保证基本性能；不想用的人在初始化时关掉。

- **默认开**：避免"忘了开导致极慢"。
- **可关**：调试、一致性实验、启动早期需要关闭。
- **按类**：指令与数据分别有存在位与开关位。
- **风险**：关闭缓存后性能骤降，容易被误判为"实现慢"。
- **判据**：性能实验必须报告缓存开关状态。

## 3. 最后一级缓存为什么单独成 cfx？

**答：** 因为它跨核共享：每核缓存的维护命令只能管自己，而最后一级缓存必须有一个全局入口来做整机失效。

- **归属**：全系统资源（编号在共享段）。
- **寄存器**：存在性 + 一条"整机失效"命令。
- **使用场景**：DMA 前后、一致性切换、调试。
- **代价**：整机失效很贵，不能频繁做。
- **判据**：这个操作只需影响本核，还是全部核。

## 4. 物理内存区域怎么描述？

**答：** 最多 64 个不连续区域，每个区域给起始物理地址、大小、属性（可预取、一致）；重叠时编号小的优先。

- **属性**：可预取、一致；更细的属性留待多核阶段。
- **重叠规则**：按编号从小到大匹配，第一个命中的决定行为。
- **大小为零**：表示未使用。
- **范围**：只描述普通内存，**设备存储不在此**。
- **判据**：地址落在哪个区域、该区域的属性是什么。

## 5. `pmem` 里的 SRAM 怎么用？

**答：** 它是一段固定的 64 KiB 内部存储，CPU 用普通访存读写；超出范围的核内偏移触发核内地址错误。

- **位置**：固定在内部偏移的高端，地址可由 cfx 编号与偏移算出。
- **访问**：普通 `ld/st`，同步。
- **越界**：报 `CFXMEM`。
- **用途**：作为 DMA 的暂存区（避免设备直接访问任意物理内存）。
- **权限**：访问权限由两轴模型的核内访存掩码控制。

## 6. DMA 怎么工作？

**答：** 五个寄存器：源、目的、长度、控制、状态；方向二选一；异步执行，完成后置完成位或错误位，并可产生异步异常。

- **方向**：SRAM → 物理内存，或物理内存 → SRAM。
- **地址**：64 位寄存器，CFX 侧只取低 42 位、物理侧只取低 56 位，高位忽略。
- **长度**：30 位，1 到 512 MiB。
- **控制**：启动（自清）、方向、中断使能。
- **状态**：忙、完成（写 1 清）、错误（写 1 清）、错误码（四种：长度非法、SRAM 越界、物理越界、物理不可访问）。
- **异步**：完成前不得复用 SRAM 与寄存器；中断使能时完成或出错会触发 `PMEM_DMA`。
- **路由**：当前实现投递到本核的物理内存异常入口。

## 7. 维护次序为什么固定？

**答：** 因为三者有依赖：页表改了不失效 TLB，会用到旧映射；TLB 失效了不清缓存，会读到旧数据。

- **顺序**：改页表 → 失效 TLB（含回写 A/D）→ 清相关缓存。
- **DMA 前后**：搬运前回写缓存，搬运后失效缓存。
- **遗漏后果**：偶发读到旧值、写到错误物理页。
- **判据**：能否指出每一步"防的是什么"。

## 背景知识

### 术语与概念

- **每核缓存**：指令与数据缓存。
- **最后一级缓存**：跨核共享的末级缓存。
- **物理内存区域**：不连续的 DRAM 段描述。
- **内部 SRAM**：cfx 自带的块存储。
- **DMA**：不经过 CPU 的块搬运。
- **维护命令**：失效与回写。

### 对照

**存储层次管理**

- **按层分 cfx**：每核缓存 / 末级缓存 / 物理内存（本设计）。
- **单一缓存指令**：传统 ISA 常见。
- **判据**：共享资源能否有全局入口。
