# 资源管理 -- 时间与中断

**本册要点**

- **全局时间**（time）是系统级自由运行计数器：只读、不产生中断、所有核共享。
- **本地计数**（hart）每核私有：hart 编号、周期数、退休指令数。
- **本地定时器**也在 hart：比较值 + 控制（使能/屏蔽/状态），匹配时产生可屏蔽中断。
- **核间中断**（IPI）由 hart 投递，携带来源核编号。
- 中断是电平触发、指令边界检查、低编号 cfx 优先。
- 时间基准统一靠全局计数器，不靠各核自己算。

## 1. 为什么时间与本地计数分开？

**答：** 因为"全系统同一时刻"和"这个核跑了多少"是两件事：前者必须全局一致，后者必须每核独立。

- **全局时间**：共享、自由运行，所有核读到同一值。
- **本地计数**：周期数与退休指令数，每核不同。
- **用途**：时间用于超时与调度；计数用于性能分析。
- **判据**：这个数值跨核是否应相同。

## 2. 全局时间怎么用？

**答：** 只读两个寄存器：频率与当前值；它不产生中断，定时要靠 hart 的比较器。

- **频率**：硬件给出，软件据此换算时间。
- **当前值**：64 位自由运行。
- **无中断**：避免"全局计数器给哪个核发中断"的歧义。
- **换算**：时间 = 计数值 / 频率；注意溢出与精度。
- **判据**：跨核比较时间是否一致。

## 3. 本地定时器怎么工作？

**答：** 写比较值，使能后由硬件比较全局时间与比较值；匹配时置状态位，屏蔽位为 0 则产生定时器中断。

- **比较值**：绝对时间，单位同全局时间。
- **控制**：使能、屏蔽、状态（只读）。
- **触发**：全局时间 ≥ 比较值时置状态。
- **清除**：写新的比较值即清除本次条件；写全 1 关闭。
- **代价**：每次定时都要重写比较值（单次触发模型）。

## 4. 核间中断怎么用？

**答：** 一个核向另一个核投递中断，携带来源核编号；接收方按掩码决定投递还是挂起。

- **来源**：低 6 位有效，标识发起核。
- **可屏蔽**：属异步中断，受两层掩码控制。
- **用途**：核间同步、唤醒、TLB 失效广播。
- **注意**：投递不等于立即处理，可能挂起到待处理位。
- **判据**：接收方能否知道"谁发的"。

## 5. 中断为什么是电平触发、低编号优先？

**答：** 电平触发保证"源还在就一直有效"，不会因一次采样错过；低编号优先给了一个确定、可预测的仲裁顺序。

- **电平**：掩码解除后若待处理位仍为 1，下一指令边界触发。
- **优先级**：多个 cfx 同时中断时编号小的先处理。
- **同 cfx 多原因**：按该 cfx 自己的原因优先级。
- **风险**：高编号可能饿死，软件需轮转。
- **判据**：仲裁结果是否与到达顺序无关、只与编号有关。

## 6. 多核时间基准怎么统一？

**答：** 用同一个全局计数器；各核只读它，不各自累加，避免漂移。

- **统一源**：全局时间。
- **本地偏移**：若需要"每核视角的时间"，由软件加偏移。
- **漂移**：各自累加必然漂移。
- **判据**：两个核同时读，差值是否稳定。

## 背景知识

### 术语与概念

- **全局时间**：系统级自由运行计数器。
- **本地定时器**：每核比较器 + 控制。
- **IPI**：核间中断。
- **待处理位**：被屏蔽中断的挂起记录。
- **电平触发**：源有效即触发。

### 对照

**时间与定时**

- **全局计数器 + 每核比较器**：本设计。
- **每核独立计数器**：简单但会漂移。
- **判据**：跨核时间是否可比。
