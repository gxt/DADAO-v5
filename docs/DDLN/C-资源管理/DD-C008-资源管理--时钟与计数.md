# 资源管理 -- 时钟与计数

**本册要点**

- `timer` cfx：`timer_ctrl`（enable/mode/dir）、8 个计数器。
- one-shot/periodic；增/减计数。
- `hart` cfx：`hart_id`、cycle、insn。
- 多 hart 需要共同 timebase；中断按 pending 路由。
- cycle/insn 是 per-hart 本地计数。

## 1. 为什么 timer 是 cfx，而不是 `rdtime` 一条指令？

**答：** 因为 timer 不只是“读一个时间值”，还要配置使能、模式、方向、多个计数器；做成 cfx 后，这些控制/状态都走统一的 cfx 寄存器模型。

- **`timer_ctrl`**（cg10 rc7）：bit0 enable、bit1 mode（one-shot/periodic）、bit2 dir（decrement/increment）。
- **`timer_regs[0..7]`**（cg10 rc8–15）：8 个计数器。
- **为什么不是 `rdtime`**：`rdtime` 只能读；timer 还要写控制、读状态、处理到期。
- **对比**：x86 TSC/HPET；ARM generic timer；RISC-V `mtime`/`mtimecmp`；MIPS CP0 `Count`/`Compare`；SPARC `tick`；PowerPC timebase/decrementer——都有“读 + 比较/控制”两部分，cfx 把它们统一。

## 2. 为什么 `timer` 有 8 个计数器？one-shot/periodic、增/减计数怎么选？

**答：** 8 个计数器让一个 cfx 能同时服务多个定时需求（不同 hart/不同用途），不用为每个定时器开一个 cfx；one-shot/periodic、增/减计数由 `timer_ctrl` 的 mode/dir 位选。

- **数量**：`timer_regs[0..7]`，8 个。
- **mode**：0=one-shot（到点停），1=periodic（到点重装）。
- **dir**：0=decrement（倒数），1=increment（正数）。
- **为什么**：多个定时源共享一套控制/状态；减少 cfx 数量。
- **对比**：x86 HPET 有多个比较器；ARM generic timer 有 EL 定时器；RISC-V 有 `mtimecmp` 多个 hart 比较器。

## 3. 为什么 cycle/insn 计数放在 `hart` cfx，而不是 `timer`？

**答：** 因为 cycle/insn 是“这个 hart 的流水线”本地计数，不是全局时间；放到 `hart` cfx 才能按 hart 隔离。

- **`hart_id`**：hart 编号。
- **`cycle_lo/hi`**：本地周期数。
- **`insn_lo/hi`**：退休指令数。
- **为什么**：每个 hart 有自己的计数；`timer` 更偏“时间/定时”。
- **对比**：x86 的 TSC 是 per-core；ARM 的 `CNTPCT` 是 per-core；RISC-V 的 `mcycle`/`minstret` 是 per-hart。

## 4. 多 hart 时，时间基准怎么统一？中断怎么路由？

**答：** 多 hart 需要一个共同的 timebase（或按 hart 校准的偏移）；到期中断通过 pending 位进入对应 cfx 的 handler，具体路由按实现/测试机约定。

- **timebase**：共享计数器或每 hart 的同步计数；软件负责校准。
- **中断**：到期置 pending；按 cfx 的 mask/向量进入 handler。
- **多 hart**：每个 hart 可以有自己的 timer 实例；共享 timer 要仲裁。
- **待核**：timer cfx 是 per-hart 还是共享、到期中断具体进哪个 cfx，按实现/规范核对。
- **对比**：x86 的 TSC 同步/HPET；ARM 的 generic timer 比较器；RISC-V 的 `mtimecmp` + PLIC/CLINT；MIPS/SPARC/PowerPC 的 per-CPU 定时器。

## 背景知识

### 术语与概念

- **one-shot**：计时到点一次即停。
- **periodic**：到点后自动重装，周期触发。
- **cycle count**：hart 本地周期计数。
- **instruction count**：hart 本地退休指令计数。
- **时间基准**：多 hart 共享的全局时间参考。

### 对照

**x86-64**：TSC（时间戳计数）+ HPET。

**ARM64**：generic timer（`CNTPCT`/`CNTVCT`）。

**RISC-V**：`mtime`/`mtimecmp` + `mcycle`/`minstret`。

**MIPS**：CP0 `Count`/`Compare`。

**SPARC**：`tick` 寄存器 + 系统计数器。

**PowerPC**：timebase（`TB`）+ decrementer。
