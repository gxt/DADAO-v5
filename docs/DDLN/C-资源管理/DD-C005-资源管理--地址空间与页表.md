# 资源管理 -- 地址空间与页表

**本册要点**

- CPU 地址固定 **48 位**：`addr[47:42] = 0` 是内存窗口（虚拟地址 42 位），`1–63` 是各 cfx 内部空间。
- 物理地址 **56 位**；虚拟地址与物理地址是两套空间，内存窗口**必须**经页表转换。
- **只有一个页表基址寄存器**（不是数组），64 KiB 对齐，无有效位。
- 页大小 64 KiB；支持 512 MiB 超页；两者都再分为 **8 个小页**（临时缺页粒度）。
- 权限三件：HSJU（模式许可）+ R/W/X（操作许可）+ 页表有效性；检查有固定优先级。

## 1. 48 位地址怎么分区？

**答：** 高 6 位选分区：`0` 是内存窗口，`1–63` 是 cfx 内部空间；内存窗口的虚拟地址只有 42 位，cfx 内部偏移也是 42 位。

- **内存窗口**：`VA[41:0]`，经页表转成 56 位物理地址。
- **cfx 内部空间**：`addr[41:0]` 是该 cfx 的内部偏移，直接访问。
- **`cfx0` 没有内部空间**：它只负责陷入。
- **两个空间不互通**：cfx 核内地址不等于物理地址，也不能直接当内存用。

## 2. 页表关掉时为什么不直通物理内存？

**答：** 因为关掉转换意味着"没有地址映射"，而不是"地址就是物理地址"；直通会让内核与用户共享同一套地址，隔离无从谈起。

- **`ptw_enable = 0`**：内存窗口访存触发 `CFXMEM`（含取指）。
- **复位值**：0，所以复位后必须先建映射再开。
- **cfx 内部空间不受影响**：它不经过转换。
- **判据**：任何"让 0 号分区直通"的设计都会破坏隔离。

## 3. 为什么只有一个页表基址？

**答：** 因为地址空间切换靠"换页表基址 + 换 ASID"，而不是靠选择器；单个基址 + ASID 已经能表达多进程。

- **寄存器**：只存物理页号高位，64 KiB 对齐；低 16 位强制 0。
- **无有效位**：是否使用由 `ptw_enable` 决定。
- **切换方式**：写基址或写 ASID，然后**显式**失效 TLB。
- **为什么不用数组**：数组选择器会引入"当前用哪一项"的额外状态，且掩盖了"切换必须失效 TLB"这件事。

## 4. 两级页表怎么索引？

**答：** 一级用 `VA[41:29]`，二级用 `VA[28:16]`，页内偏移 `VA[15:0]`；每级 2^13 项、每项 8 字节，正好 64 KiB 一页。

- **普通页**：L1 索引 13 位 + L2 索引 13 位 + 偏移 16 位。
- **超页**：L1 索引 13 位 + 29 位页内偏移（512 MiB）。
- **页表访问用物理地址**：不经过转换；页表页必须在物理存储器里。
- **按目标端序**：页表项按大端存放。
- **为什么是 64 KiB**：一级页表刚好一页，索引计算简单。

## 5. 页表项里有什么？

**答：** 模式许可（HSJU）、物理页号、小页存在位、读写执行许可、全局位、访问/修改位、超页位、有效位。

- **HSJU**：四位分别对应 H/S/J/U，当前模式对应位为 1 才允许。
- **PPN**：物理页号，对齐低位由硬件清零。
- **小页存在位**：超页用 `SPF`（8 位，每 64 MiB 一位），普通页用 `GPF`（8 位，每 8 KiB 一位）。
- **R/W/X**：取指要 X、读要 R、写要 W。
- **G**：全局页跨 ASID 复用。
- **A/D**：访问位与修改位，由硬件在 TLB 条目中维护并回写。
- **SP/P**：超页标志与有效位。

## 6. 小页（fragment）解决什么问题？

**答：** 解决"按需加载时一次要搬整页"的问题：一页分 8 份，可以只把用到的部分放进内存；它省的是**外存 I/O**，不是物理内存。

- **超页**：512 MiB 分 8 份，每份 64 MiB。
- **普通页**：64 KiB 分 8 份，每份 8 KiB。
- **位图**：`SPF` / `GPF` 每位对应一份，0 表示不在内存。
- **不需要按需加载时**：全置 1，等价于整页加载。
- **代价**：页表检查多一次位测试。

## 7. 权限与异常优先级怎么定？

**答：** 先看页表有效性（缺页/超页缺失/小页缺失），再看模式许可（HSJU），最后看读写执行许可；同一访问只报优先级最高的那个。

- **优先级**：取指对齐 → 非法/未定义指令 → 访存对齐 → 页表异常。
- **页表内部**：L1 缺失 → 超页缺失 → 超页小页缺失 → L2 缺失 → 普通页小页缺失 → 模式许可 → 读写执行许可。
- **前缀**：取指异常带 `I`，数据异常带 `D`。
- **统一入口**：页表相关异常都进页表 cfx。
- **判据**：多个条件同时成立时，只报一个，且可预测。

## 背景知识

### 术语与概念

- **内存窗口**：`addr[47:42]=0` 的分区。
- **超页**：512 MiB 的大页。
- **小页（fragment）**：页内的 8 分之一，按需加载粒度。
- **HSJU**：四种模式的访问许可位。
- **A/D**：访问位与修改位。
- **ASID**：地址空间标识。

### 对照

**页表设计**

- **两级 64 KiB 页 + 超页 + 小页**：本项目。
- **多级 4 KiB 页**：常见通用设计。
- **判据**：页表大小、TLB 覆盖、按需加载粒度。
