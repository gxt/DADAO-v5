# 系统集成 -- 导论

**本册要点**

- "一个能用的系统" = 内核 + C 库 + 动态链接器 + init + 工具集 + 根文件系统 + 启动链，缺一件都跑不到用户态。
- 三条装配路线：从零自举（LFS 式）、用现成包（发行版/嵌入式发行）、混合。
- 与相邻系列的分工：D 给环境约束，E 给工具链，G 给内核契约，F 给验证，本系列给**装配**。
- 可复现 = 固定版本 + 固定选项 + 记录哈希；否则"能跑"不可复制。
- 失败形态很集中：启动卡住、找不到动态链接器、库版本不匹配、缺设备节点。

## 1. 什么算"一个能用的系统"？

**答：** 能从复位走到"能执行用户程序并正常退出"：引导加载器 → 内核初始化 → 挂载根文件系统 → 启动 init → 跑起 shell 与基本工具。

- **内核**：内存管理、进程、中断、驱动最小集。
- **C 库 + 动态链接器**：程序能装载、能调用系统调用。
- **init**：第一个用户态进程，负责启动其余服务。
- **工具集**：shell、核心工具（文件、文本、进程管理）。
- **根文件系统**：目录布局、设备节点、配置文件。
- **启动链**：引导加载器与内核参数、根文件系统位置。

## 2. 三条装配路线怎么选？

**答：** 自举最可控也最慢；用现成包最快但受制于他人取舍；混合最实用——用现成包搭骨架，自建关键部分。

- **从零自举**：全部从源码构建，理解最透，成本最高，适合教学与定制。
- **现成包**：发行版或嵌入式发行提供的包，快，但版本与选项不由你定。
- **混合**：工具链自建、用户态用包、内核自建——多数项目的实际做法。
- **判据**：目标是"理解系统"还是"尽快有系统"。

## 3. 与相邻系列怎么分工？

**答：** D 给环境约束（能不能跑某类库），E 给工具链（怎么造），G 给内核契约（系统调用语义），F 给验证（启动与接口怎么判），本系列给**把这些装到一起**。

- **D**：平台与载体；决定可行集合（裸机没有动态链接器）。
- **E**：编译、汇编、链接、ABI；本系列只讲"怎么用它们装配"。
- **G**：内核怎么用架构机制；本系列不重复内核实现。
- **F**：启动判定、接口测试；本系列产出"可被测试的系统"。
- **本系列**：库选型、工具集裁剪、根文件系统、镜像。

## 4. 可复现怎么保证？

**答：** 三固定一记录：固定版本、固定配置、固定构建顺序，记录哈希与命令。

- **版本**：工具链、库、工具集、内核各自锁定。
- **配置**：编译选项与裁剪配置入库。
- **顺序**：自举链的阶段顺序固定，可重放。
- **记录**：产物哈希 + 命令 + 环境清单。
- **判据**：换机器重跑得到同一哈希。

## 5. 典型失败形态有哪些？

**答：** 四类：启动卡住（无输出或有输出但停住）、找不到动态链接器、库版本不匹配、缺设备节点或权限。

- **启动卡住**：引导参数错、内核缺驱动、根文件系统位置错。
- **缺动态链接器**：解释器路径不对、库不在搜索路径。
- **版本不匹配**：库与程序对 ABI 的假设不同（如符号版本）。
- **缺设备/权限**：`/dev` 未建、init 权限不足。
- **价值**：这四类覆盖了绝大多数"装不起来"的现场。

## 背景知识

### 术语与概念

- **根文件系统**：系统启动时挂载的第一个文件系统。
- **init**：第一个用户态进程。
- **动态链接器**：加载程序并解析共享库的解释器。
- **自举链**：用宿主工具造出目标工具链，再用它造系统。
- **可复现构建**：同输入得到同产物。
- **裁剪**：按需去掉不需要的组件以减小体积。

### 对照

**装配路线**

- **从零（LFS 式）**：可控、慢、教学价值高。
- **发行版包**：快、受制于发行版。
- **混合**：务实，多数项目采用。

**系统形态**

- **裸机最小系统**：无 OS 或极简运行时。
- **嵌入式 Linux**：内核 + 精简用户态。
- **通用发行版**：完整包管理与服务。
