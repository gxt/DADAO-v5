# 运行平台 -- 观测与一致性

**本册要点**

- 同一个 bug，在不同层的**可见性**差别巨大：有的只在波形里看得见，有的只在功能级能复现。
- 观测有代价：跟踪变慢、波形巨大、探针影响时序。
- 跨载体差异必须**归因**（语义 / 时序 / 环境 / 工具），不能笼统说"不一致"。
- 一致性检查只比**架构可见状态**；时序与实现选择允许不同。
- 观测数据要与结果一起留存，否则无法复核。

## 1. 同一个 bug 在哪一层最容易看见？

**答：** 看 bug 的性质：语义错在功能级最清楚；时序/协议错在 RTL 波形里最清楚；板级与长跑问题只有实机能暴露。

- **语义错**（算错、异常原因错）→ 功能级，复现快、可单步。
- **流水线/冒险**→ 周期模型或 RTL，功能级看不见。
- **协议/握手**→ RTL 波形与断言。
- **板级/长跑**→ 实机。
- **判据**：先问"这个错需要什么信息才能观察"，再选层。

## 2. 观测手段与代价是什么？

**答：** 跟踪（指令/访存）、波形（信号）、计数器（事件统计）、日志（软件侧）；代价依次是变慢、文件巨大、需要埋点、需要改代码。

- **跟踪**：能看执行序列，但显著变慢。
- **波形**：信号级真相，文件可达 GB 级。
- **计数器**：开销小，能长期开，但只看预设事件。
- **日志**：最轻，但依赖软件埋点。
- **原则**：先低成本手段定位范围，再用高成本手段看细节。

## 3. 跨载体差异怎么归因？

**答：** 四类：语义（必须一致却没一致）、时序（允许不同）、环境（缺设备/缺内存/缺接口）、工具（模拟器或生成器自身缺陷）。

- **语义差异**：同一输入得到不同架构状态 ⇒ 缺陷，必须查。
- **时序差异**：周期数不同 ⇒ 正常，除非结论依赖时序。
- **环境差异**：某载体缺外设/内存 ⇒ 记未判定，不算失败。
- **工具差异**：模拟器 bug、生成器配置错 ⇒ 修工具，不改判据。
- **方法**：逐条登记差异 + 归因 + 处置。

## 4. 一致性检查只比什么？

**答：** 只比架构可见状态：寄存器、内存中被写区域、异常原因与现场；不比周期数、缓存状态、调试信息。

- **必须一致**：通用/浮点寄存器、内存内容、异常原因、特权状态。
- **可以不同**：周期、缓存内容、未定义行为、实现选择的顺序。
- **比较方式**：状态摘要（签名）+ 差异列表。
- **陷阱**：把"时序不同"当缺陷；把"未定义行为不同"当缺陷。

## 5. 跨层回归怎么组织？

**答：** 分层跑：功能级全量、周期级代表集、RTL 少量关键场景、实机长跑；同一用例在多层复用，只改判据。

- **复用**：同一程序/向量在不同层跑，判据按层选（语义 / 周期范围 / 协议 / 稳定性）。
- **代表集**：周期级与 RTL 只跑代表集，控制成本。
- **登记**：每层的结果分开存，避免混统计。
- **触发**：功能级进 L2/L3；RTL 与实机按需或里程碑。

## 6. 观测数据怎么留存？

**答：** 与结果同目录：日志、波形、计数器导出、配置与版本；大文件按需保留并登记路径。

- **必留**：配置、命令、版本、退出码、日志。
- **按需留**：波形、跟踪（体积大，登记路径与生成命令）。
- **关联**：用运行目录把"结果—日志—波形"绑在一起。
- **清理**：按策略清理大文件，但保留可复现命令。

## 背景知识

### 术语与概念

- **可见性**：某层能否观察到某类信息。
- **探针效应**：观测手段改变被测对象的行为。
- **归因**：把差异分到语义/时序/环境/工具。
- **状态签名**：把架构可见状态压缩成可比值。
- **代表集**：控制高层回归成本的子集。

### 对照

**观测手段**

- **跟踪**：序列真相，慢。
- **波形**：信号真相，文件大。
- **计数器**：开销小，覆盖有限。
- **日志**：最轻，依赖埋点。

**差异类型**

- **必须查**：语义、异常原因、内存内容。
- **允许**：周期、缓存、未定义行为。
- **记未判定**：缺环境。
