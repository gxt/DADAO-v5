# 运行平台 -- 评测方法

**本册要点**

- 评测第一条不是"跑多快"，而是"**这个数字能说明什么、不能说明什么**"。
- **预热与稳态**决定统计区间；冷启动数字不能代表稳态。
- 重复与方差必须报；单次结果不构成结论。
- 指标口径是陷阱区：均值类型、归一化方式、单位换算都会改变结论。
- 实验设计四件套：基线、消融、敏感性、上界。
- 参数扫描要控制变量，否则得到的是"组合效果"而非"算法效果"。

## 1. 为什么先定"可信范围"？

**答：** 因为同一个数字在不同前提下意义完全不同：冷启动还是稳态、单程序还是程序集、同配置还是跨配置。先写清前提，才知道能得出什么结论。

- **前提四项**：配置、程序/轨迹、预热条件、所在抽象层。
- **结论强度**：相对比较 > 趋势 > 绝对值。
- **外推**：只能沿"前提不变"的方向外推。
- **记录**：结果文件里必须带这四项，否则事后无法解释。

## 2. 预热与稳态怎么判断？

**答：** 跳过冷启动阶段（缓存填充、分支预测器训练、JIT/库初始化），用区间统计而非全程平均；判断稳态可看指标随时间的收敛。

- **为什么必须预热**：冷启动阶段的缺失率与分支误预测远高于稳态。
- **怎么跳**：按固定指令数或固定时间跳过，或按指标收敛判断。
- **报告要求**：明确写出"跳过了多少""是否含冷启动"。
- **陷阱**：预热太长会掩盖真实启动成本；太短会污染统计。

## 3. 重复与方差怎么报？

**答：** 至少三次，报中位数与波动范围；确定性模型（仿真）重复结果相同，也要说明"确定性"而不是省略。

- **仿真**：通常确定性，重复是为了确认配置与输入一致。
- **实机**：受温度、供电、调度影响，必须多次。
- **报告**：中位数 + 最小/最大，或均值 + 标准差。
- **陷阱**：只报最好的一次；用单次结果做显著性判断。

## 4. 指标口径有哪些陷阱？

**答：** 三类：均值类型（算术 vs 几何）、归一化基准、单位与量纲。

- **算术平均 vs 几何平均**：比率型指标（加速比）用几何平均，否则会被大值主导。
- **归一化**：相对谁的比值？基线换了，结论就变了。
- **单位**：周期、纳秒、指令数不可混用；频率假设要写明。
- **聚合**：按程序等权还是按指令数加权，结果可能相反。
- **报告**：每个指标写清定义与聚合方式。

## 5. 实验设计四件套是什么？

**答：** 基线（对照）、消融（去掉某机制）、敏感性（改一个参数）、上界（理想策略），四者合起来才能说明"这个机制值不值"。

- **基线**：同配置下关掉被测机制。
- **消融**：逐步去掉组件，看各自贡献。
- **敏感性**：单参数扫描，观察结论是否稳定。
- **上界**：最优替换/理想预取等，给出可达上限。
- **价值**：没有基线的"提升"没有意义；没有上界的"改进"不知还有多少空间。

## 6. 常见失真有哪些？

**答：** 单程序结论、只报最优参数、跨配置比较、忽略编译选项、把仿真当硅、用平均值掩盖分布。

- **样本失真**：单程序/单轨迹外推。
- **选择失真**：只报调好的参数。
- **配置失真**：比较时改了多个变量。
- **层次失真**：周期模型数字当真实芯片。
- **聚合失真**：平均值掩盖长尾。

## 背景知识

### 术语与概念

- **稳态**：指标随时间趋于稳定的阶段。
- **预热**：进入稳态前的跳过区间。
- **几何平均**：比率型指标的常用聚合方式。
- **消融实验**：逐个去掉机制看贡献。
- **敏感性分析**：单参数变化对结论的影响。
- **上界分析**：理想策略给出的性能上限。
- **归一化**：相对基线的比值。

### 对照

**指标聚合**

- **算术平均**：适合绝对量（如周期数）。
- **几何平均**：适合比率（如加速比）。
- **加权平均**：按指令数或时间加权。

**实验设计**

- **有基线**：结论可比较。
- **有消融**：贡献可分解。
- **有上界**：空间可知。
- **缺一项**：结论强度下降。
