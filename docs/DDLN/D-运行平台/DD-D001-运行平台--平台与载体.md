# 运行平台 -- 平台与载体

**本册要点**

- 三个正交维度：**运行环境**（裸机 / 用户态 / 完整系统）× **抽象层次**（功能 / 周期 / RTL / 实机）× **粒度**（语义 / 周期 / 性能）。
- **评测不是某一层的专职**：每个载体都承担评测，只是能回答的问题不同。
- **评测能力矩阵**是全系列的唯一真源：问题 → 哪个载体能答。
- **可信度阶梯**：越往下越真、越慢、越贵；每层的数字都有外推边界。
- 选择顺序永远是"**先定问题，再选载体**"，不是"手头有什么就用什么"。
- 跨载体一致性单列，因为同一个程序在不同层的差异需要归因，而不是"谁对谁错"。

## 1. 三个维度是什么？

**答：** 运行环境决定"软件跑到哪一层"，抽象层次决定"硬件模型有多真"，粒度决定"看的是语义还是时序"。三者独立，混在一起就会把"用户态"和"周期级"当成同一类选项。

- **运行环境**：裸机（无 OS）、用户态（成品系统上跑程序）、完整系统（引导 + 驱动 + 系统调用）。
- **抽象层次**：功能级（只保证架构可见结果）、周期级（建模流水线/缓存）、RTL 级（门级/总线）、实机（芯片或 FPGA）。
- **粒度**：语义（结果对不对）、周期（多少拍）、性能（吞吐/延迟/功耗）。
- **组合方式**：例如"裸机 + 功能级 + 语义"是最快的语义验收；"完整系统 + 周期级 + 性能"是性能研究。

## 2. 评测能力矩阵怎么用？

**答：** 行是"要回答的问题"，列是载体；格子里写"能 / 不能 / 只能近似"。选载体时先找到那一行，再看哪列能用。

- **语义正确性**：功能级 ✅、周期级 ✅、RTL ✅、实机 ✅；功能级最快。
- **缓存/预取/替换策略差异**：轨迹驱动 ✅（最快）、周期级 ✅、RTL ✅（最慢）。
- **分支预测准确率与代价**：轨迹驱动 ❌（没有控制流）、周期级 ✅、RTL ✅。
- **整机 IPC / 端到端性能**：功能级 ❌、周期级 ✅（相对值）、RTL/实机 ✅（更真）。
- **时序收敛 / 面积 / 功耗**：只有 RTL + 综合、实机实测。
- **长时间稳定性 / 板级问题**：只有实机。
- **门控用法**：这张矩阵是唯一真源，各册只引用，不另画一张不同的表。

## 3. 可信度阶梯怎么理解？

**答：** 功能 → 周期 → RTL → 实机，越往下越接近真实硬件，代价也越高；每层能外推的范围不同，写结论必须标出处在哪一级。

- **功能级**：只保证架构可见状态；**不能**给出任何时序结论。
- **周期级**：同配置下的**相对比较**可信；绝对值依赖模型精度与配置。
- **轨迹驱动**：只对访存类结论成立；缺控制流与数据依赖。
- **RTL**：周期精确，但仍是仿真；不等于综合后时序，更不等于硅。
- **实机（FPGA）**：真实频率与板级行为，但受板卡与布线限制；**不是 ASIC 的频率/功耗**。
- **写作要求**：每个数字都要标"配置 + 程序/轨迹 + 预热条件 + 所在层"。

## 4. 选择判据是什么？

**答：** 先问"我要回答什么问题"，再问"这个问题需要多真的模型"，最后才看"哪个载体现在可用"。反过来（先看手头工具）是最常见的误用来源。

- **问题类型一：对不对** → 功能级，够快够全。
- **问题类型二：差多少**（两个方案比较）→ 周期级或轨迹驱动，同配置相对比较。
- **问题类型三：能不能收敛/多大面积** → RTL + 综合。
- **问题类型四：真实频率/板级** → 实机。
- **兜底原则**：能用低层回答的，不要上高层；必须上高层时，先想清楚"低层能不能给出同样的结论"。

## 5. 常见误用有哪些？

**答：** 四类：用功能级评性能、用周期级判语义、用轨迹驱动评分支预测、用 FPGA 频率当 ASIC 指标。

- **功能级评性能**：QEMU 的指令计数不是周期数，只能做粗略规模估计。
- **周期级判语义**：模型有自己的 bug，语义判据必须来自规范与功能级。
- **轨迹驱动评分支预测**：轨迹里没有分支结果，评不出来。
- **FPGA 频率当 ASIC**：布线、时钟约束、板级供电都不同，不能直接换算。
- **共同根因**：把"能跑"当成"能评"。

## 6. 为什么跨载体一致性要单列？

**答：** 因为同一个程序在不同层的行为差异，既可能是缺陷也可能是正常差异（时序、未定义行为、环境缺失）；不单列就无法归因，最后变成"谁都说自己对"。

- **必须一致**：架构可见状态（寄存器、内存、异常原因）。
- **可以不同**：时序、缓存行为、未定义行为的实现选择。
- **差异归因**：语义错 / 时序差 / 环境缺失 / 工具缺陷。
- **做法**：同一向量跨层跑，只比"必须一致"的部分；差异逐条登记。

## 背景知识

### 术语与概念

- **运行环境**：裸机 / 用户态 / 完整系统。
- **抽象层次**：功能级 / 周期级 / RTL 级 / 实机。
- **粒度**：语义 / 周期 / 性能。
- **评测能力矩阵**：问题 × 载体的可用性表。
- **可信度阶梯**：越往下越真越慢。
- **外推边界**：某层结论适用的范围。
- **跨层一致性**：只比架构可见状态的差异检查。

### 对照

**载体定位**

- **功能级模拟**：语义与覆盖最快，不评性能。
- **执行驱动周期模型**：微架构与性能研究，同配置相对比较。
- **轨迹驱动模型**：存储类算法快速迭代，范围窄。
- **RTL 仿真**：时序/面积/总线，慢。
- **FPGA**：真实频率与板级，仍非硅。

**选择依据**

- **先定问题**：对不对 / 差多少 / 收敛与面积 / 真实频率。
- **再定层次**：功能 / 周期 / RTL / 实机。
- **最后看可用性**：手头有什么工具。
