# 操作系统 -- 启动链与早期控制台

**本册要点**

- 复位后从**启动 ROM** 的固定向量取指；该空间必须可执行、只读。
- 内核入口只做三件事：**建早期映射、设栈、清数据段**，然后进 C 代码。
- 早期控制台必须**轮询**：中断还没通，不能等中断。
- 正式控制台要等中断与时钟就绪后再切。
- 启动参数用固定结构传递，不依赖"约定俗成的寄存器"。

## 1. 复位后第一条指令从哪来？

**答：** 从电源 cfx 下的启动 ROM：复位向量固定在 ROM 内某个偏移，硬件直接从那里取指。

- **空间**：256 KiB，只读，必须可执行。
- **向量**：固定地址，不随内存布局变化。
- **第一件事**：设置栈与早期环境，然后跳到内核入口。
- **为什么放 ROM**：上电时内存控制器未必就绪，只有 ROM 一定可读。
- **失败表现**：复位后无任何输出，或取指异常。

## 2. 内核入口要做什么？

**答：** 三件事：建最简映射（把自己映射到虚拟地址）、设栈、清数据段；完成后跳进 C。

- **早期映射**：只映射内核自身与串口，页大小与权限按最小集合。
- **栈**：静态分配一块，避免依赖内存分配器。
- **数据段**：清零未初始化段，拷贝已初始化段。
- **参数**：从启动结构里取出内存大小、根文件系统位置、控制台参数。
- **判据**：能否在 C 代码里打出第一行。

## 3. 为什么早期控制台必须轮询？

**答：** 因为此时中断还没通、时钟还没校准；等中断会永远等下去。

- **轮询方式**：直接读写串口寄存器，检查发送就绪位。
- **粒度**：只支持同步输出，不支持输入。
- **价值**：它是后面所有调试的基础。
- **切换时机**：中断与时钟就绪、驱动注册完成后再切。
- **反例**：早期就用中断驱动控制台，结果一行日志都打不出来。

## 4. 什么时候切到正式控制台？

**答：** 当异常向量装好、时钟事件可用、串口中断能投递之后；切换前要保证"新路径失败时还能退回轮询"。

- **前置条件**：向量、时钟、串口中断三者就绪。
- **切换方式**：注册正式控制台，早期控制台降级为后备。
- **回退**：新路径出问题时能临时切回轮询。
- **判据**：切换后日志仍连续、不丢行。
- **代价**：两套输出路径要维护一段时间。

## 5. 启动参数怎么传？

**答：** 用一块固定格式的结构（内存描述、根文件系统、控制台、命令行），由引导方填好、内核解析。

- **内容**：内存区域、根文件系统位置与类型、控制台参数、命令行。
- **校验**：魔数 + 版本，防止解析错位。
- **兼容**：字段只增不改；保留字段写零。
- **位置**：由引导约定固定，内核早期就能读到。
- **判据**：换一个引导方，参数仍能解析。

## 6. 启动失败怎么定位？

**答：** 按层查：无输出 → 引导或取指；有输出但停住 → 映射或栈；进了 C 但没到初始化 → 参数或内存。

- **无任何输出**：启动 ROM、向量、串口初始化。
- **有输出后停**：早期映射、栈、数据段。
- **进了 C 但很早退出**：参数结构、内存大小。
- **走到初始化但卡住**：时钟与中断（见异常册）。
- **手段**：最小化输出、逐段打印标记、用退出码。

## 7. 各家内核怎么做（对照）

**答：** 启动链的共同结构是"固件 → 引导 → 内核 → 控制台"，但每层的接口与调试手段差别很大。

- **Linux**：引导加载器 + 启动协议传参，早期控制台有专门机制（earlycon）。
- **FreeBSD**：三段式引导（引导块 / 加载器 / 内核），早期串口靠加载器环境变量。
- **Windows**：引导管理器 → 系统加载器，早期问题靠内核调试器（串口或网络）。
- **macOS**：固件 → 引导程序 → 内核，早期日志走串口或调试器。
- **Minix**：引导监视器直接加载内核与服务，控制台早期轮询。
- **Unix（历史）**：从磁盘固定块的自举程序链式加载。

**是统一标准吗**：不是；共同点是"每层都要有一个能看得见的输出"。

## 背景知识

### 术语与概念

- **启动 ROM**：复位后可取指的只读空间。
- **复位向量**：上电后第一条指令的地址。
- **早期映射**：进 C 前建立的最小页表。
- **轮询控制台**：不依赖中断的输出方式。
- **启动结构**：引导方传给内核的参数块。

### 对照

**启动链**

- **本项目**：ROM → 内核入口 → 早期控制台 → 时钟与中断。
- **通用 PC**：固件 → 引导加载器 → 内核。
- **判据**：每一层都有可观察输出。
