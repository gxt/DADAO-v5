# 操作系统 -- 时间、中断与设备

**本册要点**

- 全局时间只读、无中断；**定时中断来自 hart 的比较器**。
- 单次触发模型：写新比较值即清除本次条件，所以时钟事件要每次重装。
- 时钟源用本地周期计数，频率由硬件给出。
- 计时精度依赖模拟器配置：没有周期推进，紧循环里收不到中断。
- 串口中断走串口 cfx；块设备首版用内存盘。
- 核间中断只留接口，单核阶段不实现。

## 1. 全局时间与 hart 定时器怎么分工？

**答：** 全局时间负责"现在几点"，hart 定时器负责"到点叫我"；两者分开，避免"谁来发中断"的歧义。

- **全局时间**：系统级、自由运行、只读。
- **hart 定时器**：每核一个比较值 + 控制（使能/屏蔽/状态）。
- **匹配**：全局时间 ≥ 比较值时置状态。
- **清除**：写新比较值即清条件；写全 1 关闭。
- **判据**：定时中断能周期性到来。

## 2. 为什么时钟事件要单次触发？

**答：** 因为硬件是"写比较值 → 到点触发 → 需要重写"的模型；没有自动重装，所以软件每次中断都要装下一次。

- **单次**：每次中断处理里写下一次的比较值。
- **周期**：软件模拟周期，用"当前 + 周期"计算。
- **漏装**：中断只来一次，之后时间停摆。
- **代价**：每次中断多几次寄存器访问。
- **判据**：连续多个周期都能收到中断。

## 3. 时钟源怎么选？

**答：** 用本地周期计数：单调、无中断、每核独立；全局时间可作为跨核一致的补充。

- **本地周期**：每核计数，适合测短间隔。
- **全局时间**：跨核一致，适合记"时刻"。
- **换算**：用频率寄存器换算成时间。
- **注意**：计数器会溢出，换算要处理回绕。
- **判据**：延时校准能收敛（不会卡在忙等）。

## 4. 计时精度为什么依赖模拟器配置？

**答：** 因为功能级模拟器默认不按周期推进；如果不开启周期精确模式，紧循环里的中断永远到不了 guest。

- **现象**：忙等"tick 变化"永不退出。
- **原因**：模拟器按块执行，中断在块边界才检查。
- **配置**：开启周期推进（如固定周期步进），让中断能插入紧循环。
- **代价**：模拟变慢。
- **判据**：延时校准函数能返回。

## 5. 串口中断怎么接？

**答：** 每个实例一位中断，进串口 cfx 的入口；处理程序读状态、清中断、收数据。

- **位编号**：按实例分配。
- **入口**：串口 cfx 的向量。
- **处理**：读状态 → 取数据 → 清中断 → 唤醒等待者。
- **早期**：控制台还没切到中断时，仍用轮询。
- **判据**：输入不会丢字节。

## 6. 块设备首版怎么做？

**答：** 用内存盘（initramfs）：把根文件系统打进内存镜像，内核直接挂载；DMA 只做存在性验证。

- **好处**：无块设备驱动、无中断、无 DMA 时序问题。
- **代价**：镜像大小受限、不能持久化。
- **DMA 的存在性验证**：跑一次小传输，确认完成位与错误位正常。
- **演进**：内存盘稳定后再做真实块设备。
- **判据**：能挂载并执行 init。

## 7. 核间中断在单核阶段怎么处理？

**答：** 只留接口：数据结构里保留核编号与投递函数，但不实现投递路径。

- **接口**：发送、接收、处理三个空实现。
- **数据结构**：每核状态数组留位。
- **为什么**：避免将来大改；但单核不测试。
- **判据**：代码里能指出"多核时需要填哪里"。
- **风险**：空实现被误用，需要在调用点加断言。

## 8. 各家内核怎么做（对照）

**答：** 时间与中断都被拆成"读时间"和"定时事件"两件事，差别在抽象层与触发模型。

- **Linux**：时钟源与时钟事件两个抽象，时钟事件常用单次触发 + 软件重装。
- **FreeBSD**：时间计数器与事件定时器两个抽象。
- **Windows**：高精度计数器 + 定时器对象，中断按优先级。
- **macOS**：绝对时间接口 + 内核定时器。
- **Minix**：时钟任务发消息驱动定时。
- **Unix（历史）**：固定节拍时钟中断，所有定时基于它。

**是统一标准吗**：不是；共同点是"读时间不能依赖中断"。

## 背景知识

### 术语与概念

- **全局时间**：系统级自由运行计数器。
- **hart 定时器**：每核比较器 + 控制。
- **时钟事件**：产生定时中断的机制。
- **时钟源**：读时间的机制。
- **单次触发**：每次中断后需重装。
- **内存盘**：根文件系统在内存中的镜像。

### 对照

**定时机制**

- **单次触发 + 软件重装**：本设计。
- **自动重装**：硬件实现，软件简单。
- **判据**：连续周期是否稳定。
