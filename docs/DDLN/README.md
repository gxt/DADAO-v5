# Dadao Lecture Notes (DDLN)

面向本科课程的 DADAO 讲义（lecnotes）。

## 指令系统

| 篇目 | 内容 |
| --- | --- |
| `A001` 指令系统--设计理念 | **设计理念 TAO**：设计顺序与 DRY；8/6/6/6/6、取消 CZSO、立即数赋值、多寄存器、条件赋值；寄存器分组与 RAS。 |
| `A002` 指令系统--指令编码 | **指令编码**：32 位定长、12 种操作数格式、`opc`/`opx`、立即数拼接、位宽子表、ILLI/UNDI、伪指令。 |
| `A003` 指令系统--寄存器设计 | **寄存器设计**：`rd`/`rb`/`rf`/`ra` 四组 × 64；RD/RB 分离；0 号寄存器；多寄存器块复制。 |
| `A004` 指令系统--条件判断 | **条件判断**：CZSO 的代价；六种条件；`br.eq`/`br.ne`；`cmp` 三值；`cs.*` 与条件写回。 |
| `A005` 指令系统--立即数处理 | **立即数处理**：分片拼接 vs 常量池；16 位片 + wyde-position；`set.*`；不同寄存器组变体。 |
| `A006` 指令系统--访存与地址运算 | **访存与地址运算**：48 位地址；RB 溢出标记；`add.o`/`sub.o`/`aip`；符号/零扩展；`ldm`/`stm`；对齐；大端。 |
| `A007` 指令系统--整数运算 | **整数运算**：`.s`/`.u` 与双目的；窄位语义；`cmp` 三值；乘除；除零/溢出定值。 |
| `A008` 指令系统--位操作 | **位操作**：逻辑运算；移位与循环；`rev`；`ctlz`/`cttz`/`ctpop`；`clmul`；`ext`。 |
| `A009` 指令系统--浮点运算 | **浮点运算**：IEEE 754 状态位；min/max；FMA；`rf0`（qNaN + 状态）；格式转换；分类；除零。 |
| `A010` 指令系统--控制流 | **控制流**：相对分支；六种条件；`jump`/`call`；RAS（寄存器栈 + 内存栈）；`ra0`；`ret`。 |
| `A011` 指令系统--原子操作 | **原子操作**：LR/SC；acquire/release；`sc` 成功/失败；`fence` 前驱后继；保留粒度；对齐。 |

## 资源管理

| 篇目 | 内容 |
| --- | --- |
| `C001` 资源管理--核芯功能扩展 | **cfx 统一建模**：6 位编号分区；四条 cfx 指令；`CFXMEM`/`CFXREG`/`ILLI`；测试机实现范围；扩展策略。 |
| `C002` 资源管理--异常与cfx切换 | **异常进入/退出**：保存现场、切模式与掩码；`escape` 返回；待处理位；优先级；两层权限；多 hart 隔离。 |
| `C003` 资源管理--cfx寄存器模型 | **两级编号**：`cg`/`rc`；通用面与专有面；scratch 2–64；只能用 cfx 指令访问，且只连 `rd`。 |
| `C004` 资源管理--cfx存储模型 | **块传输**：cfx 内部 SRAM ↔ 内存；64 B 对齐；两级定位；当前 deferred；不是 DMA。 |
| `C005` 资源管理--运行模式与资源委派 | **四模式**：user/jail/supv/hypv；`jail` 与独立监视器；`cg3`；委派位图；两层闸门；嵌套分工。 |
| `C006` 资源管理--存储层次 | **cache/llc/pmem**：维护操作；跨 hart 共享；物理内存区域属性；device 不归 pmem；维护次序。 |
| `C007` 资源管理--虚实地址转换 | **48 位 VA**：PTBR + 两级页表 + 页内偏移；`ptw` 管权限、`tlb` 管缓存；超页；TLB 异常子集。 |
| `C008` 资源管理--时钟与计数 | **timer/hart**：控制与 8 个计数器；one-shot/periodic；cycle/insn 每核计数；多 hart 时间基准与中断。 |
| `C009` 资源管理--外部设备 | **uart/power**：实例存在性；32 组 × 64 寄存器；关机/硬复位/软复位；设备存储不走 pmem；中断路由。 |
