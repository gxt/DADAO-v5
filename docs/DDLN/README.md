## 指令系统

| 篇目 | 内容 |
| --- | --- |
| `B001` 大道至简--设计理念 | **设计理念 TAO**：设计顺序与 DRY；指令系统设计（8/6/6/6/6、取消 CZSO、立即数赋值、多寄存器、条件赋值）；寄存器设计（分组、RB、RAS、rf0）。 |
| `B002` 大道至简--指令编码 | **指令编码**：32 位定长、`8/6/6/6/6`、12 种操作数格式、`opc`/`opx`、立即数拼接、位宽子表、ILLI/UNDI、伪指令。 |
| `B003` 大道至简--寄存器设计 | **寄存器设计**：`rd`/`rb`/`rf`/`ra` 四组 × 64 个；RD/RB 分离；0 号寄存器；`rd0` 只读、`rb0` = IP；多寄存器块复制。 |
| `B004` 大道至简--条件判断 | **条件判断**：CZSO 的动机与代价；六种条件 N/NN/Z/NZ/P/NP；`br.eq`/`br.ne`；`cmp` 的 -1/0/1；`cs.*` 与 `cmovcc`。 |
| `B005` 大道至简--立即数处理 | **立即数处理**：分片拼接 vs 常量池；`rwii` 的 16 位片 + wyde-position；`set.*` 伪指令；不同寄存器组的变体。 |
| `B006` 大道至简--访存与地址运算 | **访存与地址运算**：48 位地址；RB 高 16 位溢出标记；`add.o`/`sub.o`/`aip`；load 符号/零扩展；`ldm`/`stm`；对齐；大端序。 |
| `B007` 大道至简--整数运算 | **整数运算**：`.s`/`.u` 与双目的 128 位；8/16/32 位值语义；`cmp` 三值；乘除；除零/溢出定值；`add.si`。 |
| `B008` 大道至简--位操作 | **位操作**：`and.o`/`or.o`/`xor.o`/`xnor.o`；`shl`/`shr`/`rol`；`rev`；`ctlz`/`cttz`/`ctpop`；`clmul.o`；`ext`。 |
| `B009` 大道至简--浮点运算 | **浮点运算**：IEEE 754 状态位；min/max；FMA；`rf0`（qNaN + FCSR）；格式转换；比较/分类；除零。 |
| `B010` 大道至简--控制流 | **控制流**：相对分支；`br.eq`/`br.ne`；六种条件；`jump`/`call`；RAS（RegRAS + MemRAS）；`ra0`；`ret`。 |
| `B011` 大道至简--原子操作 | **原子操作**：LR/SC；acquire/release 后缀；`sc` 0/1；`fence` pred/succ；保留粒度；对齐；保留清除。 |
