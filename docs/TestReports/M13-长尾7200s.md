## 4. 名单对账

- static 72 = A 组 26 + B 组 46；dynamic 78 = A 组 34 + B 组 44；两组交集为空。
- 对全量 blocked 名单：`missing=[]`、`extra=[]`。
- 节点侧 case 目录 static 46/46、dynamic 45/45（多 1 个为首轮 `pkill` 残留目录），名单与 JSON 仍按 44 逐例对齐。
- **与 3600 s 基线的关系**：`refs/m13-001-static-3600s-full.md`（逐例 72 行）与 `refs/m13-002-dynamic-3600s-full.md`（逐例 **93** 行）是 **3600 s 预算**的基线，**不能替代本册的 7200 s/172800 s 结果**（同一批用例在两档预算下 klass 会变，例如某例 3600 s 记 blocked、7200 s 记 pass）。本册 §2.1/§2.2 才是这两档预算的逐例表。

## 5. 收尾异常（不影响数据）

包装脚本收尾时报 `rc=1`，但**数据由节点上的 `run_engine_ratio.py` 独立产出且 `ok=true`**：

- per-suite `.EXIT` 0 个；`split-A.EXIT`/`split-B.EXIT` 各 1 个（内容 `1`）
- 已知三处收尾缺陷（路径/返回码/日志前缀），均只影响 EXIT 与返回码，不触碰 90 例数据

⇒ **判据以 JSON 的 `ok` 与 `rows` 为准**，不以包装脚本 rc 为准。

## 7. 边界
