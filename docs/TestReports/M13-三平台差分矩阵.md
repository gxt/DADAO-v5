## 1. 列结构（schema）

| 列 | 含义 | 来源 |

| `档`（`link_mode`） | 基线的跑法/选例档（`static` / `dynamic`；后续任务可自定义） | 输入 JSON |
| `suite` / `case` | 冻结的用例身份（`libc-test` / `llvm-ts` / `embench` / `inst`…） | 输入 JSON |
