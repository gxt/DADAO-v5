# 计算机系统综合设计与实现 — 讲义

面向**计算机专业大三**（有理论、强实践）的课程讲义（中文，Markdown）。

## 课程目标

从零构建一个处理器系统，走通 **ISA 设计 → 指令模拟 → 汇编器 → 编译器 → 测试向量 → benchmark** 全链路；并在其上分两条路线深入：

- **路线 A**：操作系统 → LFS 构建；
- **路线 B**：chipyard 五级流水仿真 → FPGA 板。

## 讲义组织

- 按**里程碑**分目录：`M0/`（历史与理念）、`M1/`（标量核心 + 工具链 + 集成）……
- 内容按**概念/流程**分节，**不按课时切**；课时映射在各目录/课程总览中给出。
- 每篇讲义含：学习目标 / 前置知识 / 概念（就地溯源）/ 项目实例 / 动手 / 坑案例 / 小结。
