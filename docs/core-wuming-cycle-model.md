# wuming 核的指令周期模型（`Kaiwu-Tiny` / chipyard）

> **定位**：本册记录 **wuming 核（chipyard 侧）每条（族）指令的执行周期**，是**实现口径**，不是 ISA 规范。
> **真源关系**：指令的**语义**以 `spec/SimRISC-0x` 为准；本册只回答「这条指令在 wuming 上**几拍**」。
> **口径**：周期 = 从该指令进入 `EXEC` 到写回完成（**不含**取指；取指由 8-beat 缓冲摊销），访存类含一次总线往返（典型值，上界由总线决定）。
> **状态**：**§3 的「周期」列已按 `m16-chipyard-001`（2026-11-17）在 chipyard wuming 上的全量复测回填**，每一行的「来源」均为 `实测` 或 `可配`（无 `推断`/`未测`/`待实测`/`设计值`）；测量条件、采样数与逐族差异见 §5。
> **数值来源（唯一权威口径）**：本册的周期数取自 **chipyard wuming RTL 仿真实测**（trace 里相邻指令进入 `EXEC` 的拍差，`cycle=` 差值）；**权威版本 = `m16-chipyard-001` 的全量复测**（272 个 `tests/inst` 镜像、逐族 ≥2 组操作数）。gem5/QEMU 的数字不得反填本册（三平台一致只作旁证）。只有「实测」「可配」两类允许进入 gem5 时序模型。

## 1. 决策依据（用户 2026-11-10）

| 项 | 裁定 | 对本册的影响 |
|---|---|---|
| R1 | **C**：移位/位操作 2 拍、简单算术 1 拍 | 类 A 拆两档；以 **1 GHz 时序可行**为约束 |
| R2 | 乘法**周期可配**（初值 3 拍） | 类 B1 可配；**本 RTL 实测默认 1 拍**（§5「已知偏差与口径」） |
| R3 | **radix-4**（33/17/9/5 拍） | 类 B3 按宽度分档的设计意图；**本 RTL 实测 1 拍**（组合除法，见 §5） |
| R4 | 按 **hardfloat** 设计移植 | 类 B4/B5 的估计值来源 |
| R5 | 取指缓冲 **8 beat** | 取指不计入单指令周期，跨 beat 代价见 §5 |
| R7 | `ldm`/`stm` 整段预检 + **逐元素可重入**；中途总线拒绝 ⇒ `CFXMEM` | 类 D 的异常路径不改周期表 |
| R8 | 寄存器堆 **2 读 2 写**（若不可行则保守） | 类 A 的双目指令可 1 拍 |
| R10 | `swym` **1 拍** | 见 SimRISC-12 |
| R12 | 扩展 + 较大改动 `WumingCore` | 本册即该核的周期模型 |

## 4. 快路径 CPI（估计）

按典型混合比（`m12-006` §3.9）：**≈2.2**（含预取 8-beat、访存 `ld` 9 / `st` 10 拍；该估计早于 `m16-chipyard-001` 的复测，只作设计参考）。

- 若去掉预取：≈4.0（这是当初选预取的依据）
- 若不拆双 TL 端口：取指与访存互相阻塞，实测会更差

> 该值**只作设计参考**，不承诺；实际以 `cycle=` 诊断与 `m12-testcases-00x` 跑批为准。

## 5. 实测（`m16-chipyard-001` 全量复测，2026-11-17）

**方法**（本册唯一口径，沿用 `008`–`014`）：

- **载体**：`tests/inst/**/*.S` 的 **272 个镜像**（一个 opcode id 一个镜像），`llvm-mc` + `ld.lld`（`tests/ee-tiny/inst_tiny.lds`）汇编，`+loadmem=` 装进 chipyard `simulator-chipyard.harness-WumingTinyConfig` 全核准；
- **采样**：`+verbose` 打开 `WumingCore: exec ip=… inst=… cycle=…` 观测点，取**相邻两条 `exec` 的 `cycle=` 差**，归给前一条指令；若下一条不是「本指令 +4」且该指令不是控制转移，则该样本**丢弃**（中间有一次未打印的取指重填，会把别人的拍数算进来）；
- **操作数**：每个 `.S` 自带 semantic / boundary / overlap 等 5–13 个**不同操作数**用例，同族由多个镜像共同给样本 ⇒ 每族 ≥2 组操作数（见下表 n 与镜像数）；
- **取值**：静态单拍/定长族取**与取指无关的最小值**（同族中位数在少数跨 beat 采样里会被取指抬到 8，属取指代价不是指令代价）；多周期族（FP 除/开方/取余、`ldm`/`stm`）取该操作数/N 下的**中位数**；控制转移把「取指队列命中」与「跨 beat 目标」分两种情形列出；
- **取指不计入**单指令拍数（§0 口径）。跨 beat 目标的需求取指在 trace 里固定为 **+7 拍**，故 `1 + 7 = 8` 是「本拍 + 一次需求取指」。

**块传送（D）实测表**（`ldm.o`/`ldm.ub`/`stm.o`，元素数 N 取自 trace 的 `memop count=`）：

- `ldm.ub`：N=1..3 ⇒ 9/10/11，N=5 ⇒ 13，N=8 ⇒ 16，N=16 ⇒ 32，N=63 ⇒ 127；
- `ldm.o`：N=1 ⇒ 9，N=2 ⇒ 18，N=3 ⇒ 27，N=8 ⇒ 72，N=16 ⇒ 144，N=63 ⇒ 567；
- `stm.o`：同一模型 **+1**（N=1 ⇒ 10，N=8 ⇒ 73，N=63 ⇒ 568）；该 `+1` 是**每指令固定偏置、与 N 无关**（`m16-chipyard-004` 实测：362 个样本、48 个 (指令,N) 格、每格方差 0）。

⇒ 系数 `per_element = 1`、`per_beat = 8`（每 8 B 总线 beat 8 拍；`ldm.o` 的 8 beat 里 SRAM 往返 ≈7 拍主导）；`stm` 的 +1 是写完成拍，生成器从本表 `stm.o` 的 N=… 实测图解出 `n_base`（§3 的 `stm` 行即由此给值）。

**「跨 beat 取指」复核**：`020` 的预取在 `008` 被静默关掉、`022` 修复；本轮在修复后的 RTL 上重测，跨 beat 目标仍付 **7 拍需求取指**（`jump` 的 8、`trap` 的 9、`escape` 的 8 均由此而来），**同 beat 目标为 1 拍** ⇒ `009` 的「跳转 8 拍」不是上界，而是「跨 beat 目标」这一情形的实测值。

**已知偏差与口径**

- **C 类 4–7 的外推失效**（用户 2026-11-17 裁定 ①）：各宽度 `ld` 实测 **9**、`st` 实测 **10**（宽度无关、方差 0），旧的「`.o` 7–16 / 10–21、其余外推」作废；4–7 只是总线往返的估计，不含 EXEC 与写回。
- **`ld.o rf` 归 C 类**：`rf` 寄存器组只是目的寄存器不同，访存代价与其它 `ld.*` 相同（实测 9 拍），因此由 01 册 C 行覆盖，不再单列 B4 行（否则会在 gem5 里既走 B4 静态 9 拍、又走访存模型，重复计拍）。
- **`st`/`stm` 的 +1**：`st.o` = 10 与 `ld.o` = 9 的差、`stm.o` N=8 = 73 与模型 72 的差，都是同一条「写完成拍」，不是测量噪声（每宽度样本 15–7289，方差 0）。
- **B1/B3 与 R2/R3 不一致**：RTL 的乘/除是**组合实现**（`WumingALU` 的 `/`、`*`），实测 1 拍；R2「初值 3」、R3「radix-4 33/17/9/5」是设计意图，**本 RTL 未实现**。本册按实测记录，取舍留待决策（不得把设计值当实测值用）。
- **FP 除/开方 +1 与特殊操作数早退**：`014` 的 27/56 是「`fpslow start` → `fpslow-done`」；本册口径含终拍写回 ⇒ 28/57。但这两个数是**有限非零操作数**的定长路径：`NaN`/`±∞`/`0` 参与时单元 1 拍就给出结果（`fpslow-done` 与启动同拍），trace 里是 **2 拍**（`ftdiv` 8/21、`ftroot` 7/18、`fodiv` 8/21、`foroot` 7/18 样本）⇒ 「不随操作数变化」只对有限非零操作数成立。
- **MemRAS `call` 26 → 15**：`009` 的 26 是预取失效期的上界；本轮 MemRAS 溢出路径实测 15（含 7 拍需求取指）。
- **semihosting `trap` 12 拍**是宿主应答往返（harness 侧），随宿主变化；§2 F 仍写「1 + 变长」，不把它当硬件定值。
- **9 个 `_rf` 镜像的 `llvm-objdump` 断言崩溃**（`DADAOInstPrinter::getRegisterName`：`rf` 寄存器组寄存器号越界），本轮用**固定布局探针**（`.dd.t32` + 已知编码字）补测 `ftcls`/`focls`/`rf2rf`；同族的 `ldm`/`stm` 由其它寄存器组镜像覆盖。该反汇编缺陷另记 issue，不在本册修。
- 所有数字为**仿真拍数**，不含时序收敛验证。

**回填规则**：每次全量复测后把该族实测写进 §3 与本节，注明**镜像数、样本数、取值口径**；与旧值不同的行必须在这里逐条写明原因。
