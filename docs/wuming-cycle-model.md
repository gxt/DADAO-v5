# wuming 核的指令周期模型（`Machine-v5-Tiny` / chipyard）

> **定位**：本册记录 **wuming 核（chipyard 侧）每条（族）指令的执行周期**，是**实现口径**，不是 ISA 规范。
> **真源关系**：指令的**语义**以 `spec/SimRISC-0x` 为准；本册只回答「这条指令在 wuming 上**几拍**」。
> **口径**：周期 = 从该指令进入 `EXEC` 到写回完成（**不含**取指；取指由 8-beat 缓冲摊销），访存类含一次总线往返（典型值，上界由总线决定）。
> **状态**：**§3 的「周期」列已按 `008`–`014` 的实测值回填**（未实测者保留估计并标注）；逐族证据、测量条件与来源见 §5。

## 1. 决策依据（用户 2026-11-10）

| 项 | 裁定 | 对本册的影响 |
|---|---|---|
| R1 | **C**：移位/位操作 2 拍、简单算术 1 拍 | 类 A 拆两档；以 **1 GHz 时序可行**为约束 |
| R2 | 乘法**周期可配**（初值 3 拍） | 类 B1 不是固定值，评测后定 |
| R3 | **radix-4**（33/17/9/5 拍） | 类 B3 按操作数宽度分档 |
| R4 | 按 **hardfloat** 设计移植 | 类 B4/B5 的估计值来源 |
| R5 | 取指缓冲 **8 beat** | 取指不计入单指令周期，跨 beat 代价见 §5 |
| R7 | `ldm`/`stm` 整段预检 + **逐元素可重入**；中途总线拒绝 ⇒ `CFXMEM` | 类 D 的异常路径不改周期表 |
| R8 | 寄存器堆 **2 读 2 写**（若不可行则保守） | 类 A 的双目指令可 1 拍 |
| R10 | `swym` **1 拍** | 见 SimRISC-12 |
| R12 | 扩展 + 较大改动 `WumingCore` | 本册即该核的周期模型 |

## 2. 分类（按执行特性，不按指令册）

| 类 | 含义 | 周期 |
|---|---|---|
| A | 纯寄存器运算（含 R1=C 的两档） | 算术 1；移位/位域 2 |
| A2 | 条件分支 / `jump` | 1 |
| A3 | RAS 硬件栈压/弹 | 1 |
| A4 | MemRAS（需访存） | 4–7 |
| B1 | 乘法（可配） | 初值 3 |
| B2 | 16 位乘法 | 1（可配） |
| B3 | 除法/取余（radix-4） | 33 / 17 / 9 / 5（按宽度） |
| B4 | FP 加减乘/转换/分类/最小最大/缩放等 | 1–2 |
| B5 | FP 除法/开方/取余 | 单精度 ≈30；双精度 ≈56；`rem` ≈2× |
| C | 单次访存 `ld`/`st` 各宽度 | 4–7 |
| D | 多寄存器 `ldm`/`stm` | `beats × 3–4` |
| D′ | 块复制（`rd2rd` 等） | ⌈N/2⌉；`ra2rd`/`rd2ra` = N |
| E | 原子 `lr`/`sc` | `lr` 5–7；`sc` 成功 5–7、失败 2 |
| F | semihosting `trap` | 1 + 变长（等宿主应答，无上界） |
| G1/G2 | `trap` 到 cfx（`CFXTRAP`）/ 保留 cfx（ILLI） | 4–5 |
| G3 | `escape` | 3–4 |
| G4 | `cfx2rd`/`cfx2rc` | 1 |

## 4. 快路径 CPI（估计）

按典型混合比（`m12-006` §3.9）：**≈2.2**（含预取 8-beat、访存 4–7 拍）。

- 若去掉预取：≈4.0（这是当初选预取的依据）
- 若不拆双 TL 端口：取指与访存互相阻塞，实测会更差

> 该值**只作设计参考**，不承诺；实际以 `cycle=` 诊断与 `m12-testcases-00x` 跑批为准。

## 5. 实测（按族，`008`–`014` 回填）

测量方法统一为 **trace 里相邻两条指令进入 `EXEC` 的拍差**（`cycle=` 差值），抽样给多组操作数；不使用估计值或旧任务数字。

| 族 / 指令 | 实测 | 测量条件与备注 | 来源 |
|---|---|---|---|
| 单拍算术 `add.uo`/`add.si` | **1** | 同 beat 相邻指令 delta 全 1 | `018` |
| 移位 `shl.o` | **2** | 同 beat 全 2（R1=C） | `018` |
| 取指命中 | **1** | 8-beat FIFO 命中 | `018` |
| **跨 beat 取指** | 修复前 **7–8**（队列常被抽干）；**修复后 p50=1、max=1（199 次采样，>2 拍 0 次）** | `020` 的预取被 `008` 静默关掉，`022` 修复后复测 | `020` / `022` |
| 单元素 `ld.o` / `st.o` | **7–16** / **10–21** | 含背压；宽度与地址对齐影响往返次数 | `008` |
| `ldm.ub` N=8 | **16** | 1 beat + 8 拍写回 | `008` |
| `ldm.o` N=8 | **72** | 8 beat，SRAM 往返 ≈7 拍主导 | `008` |
| `stm.o` N=8 | **72** | 完成区曾写 80，reviewer 实测订正为 72（`ISS-381`） | `008` |
| 分支（不跳） | **1** | — | `009` |
| 跳转 / `call` / `ret`（RegRAS） | **8** | = 1 exec + 6 需求取指 + 1；**测量时预取失效（`prefetch=0`）** | `009` |
| MemRAS `call` / `ret` | **26 / 15** | 含一次 8B 溢出写 / 下溢读 | `009` |
| 位操作 `ctpop/ctlz/cttz/rev/rol/clmul` | **2** | 与 R1=C 一致 | `010` |
| `fence` / `swym` / `cs.*` | **1** | no-op 路径 | `010` |
| 块复制 `rd2rd` | **9**（N=8） | 1 + N | `010` |
| `lr.*` | **9** | 地址来自 `rbHD` | `010` |
| `sc.*` 命中 / 未命中 | **17 / 1** | 17 = 1 exec + 8 重读 + 8 写（**两次 SRAM 往返**，可优化为单次读改写） | `010` |
| FP 分类 `ftcls`/`focls` | **1+元素数** | 1 元素 2 拍、3 元素 4 拍 | `011` |
| FP 符号/`set.w rf`/`cs.* rf` | **1** | — | `011` |
| `rd2rf`/`rf2rd` | **1+个数** | — | `011` |
| `ld.o rf` | **13** | 单拍数据往返 | `011` |
| FP 转换（`ft2fo`/`it2fo`/`fo2ft`/`f2i`…） | **1** | 六档舍入 × 8 条 f2i 均 1 拍 | `012` |
| `ft2ft` / `fo2fo` | **1+N** | N=2 ⇒ 3；N=3 ⇒ 4 | `012` |
| FP 加/乘/FMA/比较/min-max | **1** | `foadd`/`fomul`/`fofma`/`foqcmp`/`fomin`/`fomax` 各 1 拍；结构上无 FP 等待态 | `013` |
| FP 除法/开方 | ft **27** / fo **56** | = `sigWidth+3`；7 组不同操作数（1/1、1/3、max/1、min_sub/1、sqrt 4/2/min_sub）**完全相同 ⇒ 不随操作数变化** | `014` |
| FP 取余 `forem` | **`53+d+1`** | d = 指数差；d=1/10/100/1000 ⇒ 55/64/154/1054；精确整除会因余数提前归零而早退 | `014` |

**已知偏差与口径**

- `009` 的跳转/`call`/`ret` 数字测于**预取失效期**（`008` 引入的回归，`022` 已修）。修复后跨 beat `p50=1`，因此**这些 8 拍属上界**，实际应更低；`015` 收口时复测一次并替换本行。
- `stm.o` N=8 的 72 拍（非 80）以 reviewer 实测为准；`ISS-381` 记录该订正。
- 所有数字为**仿真拍数**，不含时序收敛验证。
- `014`（FP 除法/开方/取余）的数字来自**待验收**交付；若其返工改动状态机，需同步刷新本表。

**回填规则**：`008`–`015` 每个任务完成时把该族实测回填本表并注明测量方法；`014` 已回填（本版），`015` 负责复测预取修复后的跳转类。

## 6. 维护

- **谁改**：实现该类指令的任务（`008`–`015`）回填自己的族；主会话可在收尾时统一回填并在提交里注明来源任务。`020`/`022` 负责跨 beat 取指数字。
- **怎么改**：只改「周期」与「实测」列；**不得**在本册改写指令语义（语义归 `spec/`）。
- **冲突处理**：若实测与估计差 >2×，必须在任务书登记原因（总线/状态机/时序），不得静默改数字。
- **门控**：本册为文档，不入门控；但 `020`/`019` 的实现必须使「实测」列与 `cycle=` 诊断一致。
