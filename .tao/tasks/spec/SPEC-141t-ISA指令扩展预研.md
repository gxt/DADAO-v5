## 必须给定的定性分析

对**每个**候选，逐条给出：

**A. 收益**（解决哪些 builtin / 测试 / 缺口）
- 命中的 builtin 符号 / 源文件 / issue（如 `ISS-193`(c)）；能否**消除**相应通用 C 路径或后端的 Expand / libcall；
- 收益**量级**（能删多少源 / 多少条过滤项 / 多少条 blocked），**计数现场统计、不写死**；
- 是否**重复**既有 ISA 能力（若既有指令可合成 ⇒ 须说明为何不足）。

**B. 全链代价**（逐环给触点与代价，**六环**）
1. **`spec/` 改**：`SimRISC-00…12` 正文（QFC 主表 / 类分册 / 编码）+ 章节号与计数；**须用户事先授权 + `spec-readonly` 锁更新**（`Process-06 §2/§5`）。
2. **QEMU 译码 / 执行**：`insn.decode` / `trans_*` 新增 + `scope`。
3. **LLVM 后端**：ISel lowering / 指令定义（`.td`）/ 编码（`DADAOInstrInfo` / MC /* CodeGen）。
4. **汇编器 / 反汇编 / `contracts/opcodes.yaml`**：MC 受理、反汇编回显、机器可读编码表 + 引用一致性门控（`check-scope`/`check-asm-*`/`check-isa-coverage` 等）。
5. **向量 / 门控**：`tests/vectors/**` 新向量 + L1/L2/L3 门控（`docs/Process-07`）；「一能力一向量」。
6. **既有二进制兼容**：是否**占用保留编码 / 改变既有指令语义 / 破坏已发布产物的解码**；与「只加长不缩短」/ 编码冻结口径的关系。

**C. 结论层**：每候选给 **加 / 不加 / 待定** 的**建议** + 一句理由（含**前置条件**，如「须先有后端数据」）。
