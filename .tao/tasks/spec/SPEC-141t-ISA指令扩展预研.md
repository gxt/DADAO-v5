#### 候选 A：`ror`（单向，寄存器量）+ `rori`（单向，立即量）

- **方向 = 单向 `ror`** ✓（**不含 `rol`** ✗）。**依据**：`rotl(x,n) = rotr(x,(W−n) mod W)` ⇒ **一个方向足以表达双向**；`n = 0` ⇒ `(W−0) mod W = 0` 恒等，无需特例。
- **先例**：RISC-V **只有** `ror`/`rori`（无 `rol`）；ARM32 仅 `ROR`（`ROL` 由 `ROR`/`RRX` 表达）；x86 的 `ROL`/`ROR` **成对**属 CISC 冗余 ⇒ **不作先例** ✗。
- **形态（仿既有 `shl.uo`/`shr.*`）**：
  - `orrr`：`rdHB` = 目的 / `rdHC` = 源 / `rdHD` = 旋转量（三者均 `rd` 银行），合法性沿用 `dst_rd0`；
  - `orri`：`immu6` = **0–63 自然范围**（**非 one-hot** ✗ —— `encode_onehot` 只约束 `rev.o`/`.t`/`.w`/`.b` 的块内单元位宽；本指令 `immu6` 是旋转量）⇒ **不新增**合法性规则，只复用 `dst_rd0`；
  - 语义：宽度 = **64 位**（`rd` 银行恒 64 位），循环右移量按 `mod 64` 生效。
- **收益（实测；来源 = 2026-10-17 构建树 clang `-O2` 实测，主会话提供，**本笔未重跑**）**：
  - **常量 rotate：5 条 → 1 条**（现状 = `set.zw` 常数量 ×2 + `shr.uo` + `shl.uo` + `or.o`）；
  - **变量 rotate：~9 条 → 1 条**（现状另含 `sub.uo` 取反 + UB 掩码 `and.o` ×2）；
  - **SHA-512 每轮 6 次** Σ 旋转 ⇒ 热路径 **5–9×** 指令数收敛。
- **代价（六环，逐环）**：
  1. **`spec/` 改**：`SimRISC-00` QFC 主表 **2 格**（`orrr` + `orri`）+ **归位分册**（移位/位操作类）正文 + 各册 `LEGALITY` 生成区 + 「附录：版本与变更记录」写明；`contracts/opcodes.yaml` 计数 **235 → 237**（基线 = `SPEC-145t` 收尾后现场值 235）。**须用户事先授权 + `spec-readonly` 锁更新**（`Process-06 §2/§5`）⇒ 代价 = **中**（量级同 `SPEC-145t`）。
  2. **QEMU 译码 / 执行**：`tools/qemu/generate_decodetree.py` 加 **2** 个 pattern（`insn.decode` 重生成）+ `trans_ror` 系（64 位循环右移，寄存器量 / `immu6` 统一取模）+ `scope`。代价 = **小**（照 `shr.uo` 现实现改「方向 + 取模」两处）。
  3. **LLVM 后端**：`.td` **2** 条指令定义 + 编码（`DADAOInstrInfo` / MC）+ ISel：`ISD::ROTR` **直配**；`ISD::ROTL` 须归一为 `rotr(x, (64−n) mod 64)`——**常量**可在 DAG combine 折叠（仍是 1 条），**变量**需 1 条 `sub.uo` 取负（⇒ 变量路径 2 条）**或**改由硬件按 `mod 64` 取负（**实现期二选一、须实测**）。代价 = **中**（改 `.td` ⇒ 必 `install-host`，`ISS-210`）。
  4. **汇编器 / 反汇编 / `contracts/opcodes.yaml`**：生成器产出 + `contract-isa`/`contract-asm-list` 投影 + `check-scope`/`check-asm-*`/`check-isa-coverage` 引用一致性。代价 = **小-中**（主要为自动生成面）。
  5. **向量 / 门控**：编码向量 + 语义向量（旋转量 **`0/1/31/32/63` 逐值**；`64` 按 **UB** 口径不作值断言）+ 反汇编回显 + L2 冒烟派生（「一能力一向量」）。代价 = **小**。
  6. **既有二进制兼容**：**新增格子、不改既有语义** ⇒ 既有产物解码不变；`rori` 与 `rev.*` 同处 `orri` 形态，但 `encode_onehot` 按 `mnemonic` 限定 ⇒ **无交叉约束冲突**；`opcodes.yaml` 计数增长处一律**现场派生、不写死**。代价 = **低**（须现场核目标格位空闲）。
- **被否 / 本轮不取**：
  - `fshl` / `fshr`（**双向 + 通用漏斗移位**）：语义更强（一次覆盖双向量拼接移位），但**编码面翻倍 + ISel 复杂** ⇒ **本轮不取** ✗（保留为后续候选）；
  - `rol`：**冗余** ✗（见上「依据」）。
- **建议**：**加**（单向 `ror`/`rori`）——用户已定向为 **M9 首项**；真落笔须先 **`ADR`**（跨模块 + 外部契约 + 高代价 ⇒ `docs/Process-03` 判据）+ `spec/` 逐条授权，再立执行任务。

#### 候选 B（**零新指令**）：`bswap64` 改用 `rev.o` + 单位 8 位（`k=3`）

- **做法**：`bswap64` = 64 位块内按 **8 位单元**反转单元顺序 ⇒ **`rev.o` + `immu6 = 3`（one-hot，单元 = 8 位）= 1 条**（现况 = 后端 `Expand` 十几条）。
- **性质**：**既有指令的更好用法** ✓（**不是**新指令 ✗）⇒ 不动 `spec/`、不动 QFC 主表；只需 ISel `Custom` 落 `rev.o`（`k=3`）+ 向量。
- **关系**：`LLVM-097t` 已把 `i64 = bswap` 从 `Cannot select` 收到 `Expand`（四档 rc=0）⇒ 本项是**已通过前提下的指令数优化**，可**单独立小任务**（不属 M9 ISA 扩展）。
