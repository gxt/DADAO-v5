## 背景

`spec/SimRISC-02-寄存器复制.md` 第 108–110 行的描述**不合适**：

- **108**（三句）：①「此类指令与浮点比较指令配合使用。」②「浮点比较结果存放在 rd 寄存器中：`1`（大于）、`0`（等于）、`-1`（小于）、NaN（unordered）。」③「当比较结果为 NaN 时，`cs.eq` 和 `cs.ne` 均执行 else 分支（NaN ≠ 1 且 NaN ≠ 0）。」
- **110**：「若要检测比较结果是否为 1（大于）…否则为 NaN。」

**用户裁定（2026-09-30）**：
1. **删除** 108 的**第③句**
2. 应**先说明**「NaN 的结果是**正数**，且**不为 1**」，**然后再**用 `cs.eq`/`cs.ne` 作相应处理
3. **补交叉引用**至 `SimRISC-07 §浮点比较指令`
4. 108 与 110 **合为一段**（删除其间的空行）

## 修改内容（仅 `spec/SimRISC-02-寄存器复制.md`）

**改后文本（单段，逐字采用）**：

```
此类指令与浮点比较指令配合使用（比较结果编码见 SimRISC-07 §浮点比较指令）。浮点比较结果存放在 rd 寄存器中：`1`（大于）、`0`（等于）、`-1`（小于）、NaN（unordered）。浮点比较结果为 NaN 时，其值按整型解读是**正数**，且**不等于 1**。若要检测比较结果是否为 1（大于），先将 1 加载到某个 rd 寄存器，再与比较结果做 `cs.eq`；若要检测是否不为 0（不相等），用 `cs.ne` 判断即可。若在已确认结果为正数（通过 `cs.p` 排除 0 和 -1）的前提下需进一步区分正数 1 与 NaN，检查结果是否为 1（bits[63:1]=0 且 bit0=1），否则为 NaN。
```

即：保留 108① ②；**删** 108③；在 110 的处理段**之前**插入「NaN 是正数且 ≠1」一句；**合并为一段**。
