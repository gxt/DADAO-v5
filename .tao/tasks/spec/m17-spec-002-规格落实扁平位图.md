## 背景

按 ADR-0062：`excp_cause_id` 改扁平位图；PTW 权限/访存故障只置高位位图（`[32..38]`/`[48..56]`），父 `CFXPERM`/`CFXMEM`=0；删除 `[39] NCFXPERM`、`[57] NONPTW`；不新增 cause。本任务把该模型写进 spec 与 contract 正文。

## 要做

1. `spec/DADAO-12`：
   - §2.2.6 第 6/7 步：改为「只置高位位图，不置 `CFXPERM`」；第 1 步的非 PTW 访存：`CFXMEM` 无子原因；
   - §3.6：wyde2/wyde3 表删除 `[39]`/`[57]`；「恰一位」与 wyde 归属规则按扁平模型改写（PTW 位图独立成立、父 cause 为 0；cfx 掩码/非 PTW 无子原因）；
   - §4.1–§4.6 的 `CFXMEM`/`CFXPERM` 行与 `cause_info` 指针；
   - 标注「PTW 故障的 monitor 路由与退出码：Vast，待定」（按 ADR 未定项）；
2. `.tao/contracts/contract-see.md` §6.1/§6.1.1、`contract-tlb.md` TLB-34/41 同步；
3. 变更记录：写入现有未发布 `-rc` 段；**版本号升级需用户明确认可**，未认可前只写内容；
4. 不改平台代码/测试/IDL。

## 由 ADR-0062 交接的必改项（2026-11-24）

- **oracle 迁移**：`check_ptw_regs`/`check_ptw_walk`/`check_tlb`/`check_mode_entry`/`check_causeid`/`check_vastdcache`/`k4_cow_probe` 等仍在**解析 `adr-0056` 位表**当 oracle ⇒ 本任务改正文后必须把它们改指 `contract-see §6.1.1` 或 `ADR-0062`；
- **退出码冲突**：`contract-tlb TLB-36` 与 `Kaiwu §7.1` 的 `bit3:0 = 异常位索引` 依赖低位 cause；扁平后 PTW 故障低位 cause=0 ⇒ 需按 ADR 的未定项裁定（不得自行选）；
- **`[31:16]` 保留句**：`DADAO-12 §5.2`/`contract-see §6.1` 仍写「保留」，与 2026-11-23 异步 cause 17/18 裁定不一致，本任务一并订正。
