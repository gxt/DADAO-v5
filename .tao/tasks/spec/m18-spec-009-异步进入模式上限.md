## 背景（用户 2026-11-26 裁定 B）

`escape cfx_hart` 从 supv 异步 handler 返回到被中断的 hypv 现场时，`rc8=hypv > supv`，按 `§5.1`「不得升权」会 `CFXESC`——异步打断 hypv 后无法返回。用户裁定：**只有“进入后落到 hypv”的异步中断才能打断 hypv**。

即：异步进入只能在 `当前运行模式 ≤ cg15 rc14（async_switch_run_mode）` 时发生；`rc14` 默认 2（supv），所以默认**不打断 hypv**；平台把 `rc14` 配成 3（hypv）时，才可打断 hypv（以及更低模式）。由此 `escape` 的“不得升权”判据保持原样，无需豁免。

## 目标

1. `DADAO-12 §5.4`：异步进入判定增加「`当前运行模式 ≤ cg15 rc14`」；不满足 ⇒ **不进入**（pending/事件保留，不报错、不丢）。
2. `contract-see` 同步；`cg15 rc14` 条目补“模式上限”语义（仍 RW、复位 2）。
3. 说明：默认 supv 下 hypv 不被异步打断；需要 hypv 中断的平台须显式配 rc14=hypv。
4. 版本仍 `0.8.1-rc`（内容补充，不升号）；ADR-0064 补一条 decision。
