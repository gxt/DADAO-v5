# m18-spec-004: 异步模型修订（掩码归 monitor、源索引统一 cfxha、cg9 七槽）

**模块**：spec
**项目里程碑**：M18
**依赖**：`ADR-0061`（Accepted）；`m18-spec-002` 已合入（在其文本上改）
**可并行分片**：否（spec/契约同笔）
**预估**：4–6 h（标定：同档最近 5 件派单→合入实测中位 86 min；本任务跨 SEE 多节 + 契约 + 别名重算，取 3–4×）
**档位**：大改（ISA/契约语义，复核 ≤60 min）
**状态**：已验证
**执行环境**：本地

## 背景

`ADR-0061` 修订异步模型：① 来源掩码归 monitor；② 源身份统一用 cfxha、取消 `1<<17`/`1<<18` 宏 cause；③ `cg9` 精简为 7 槽、两个位图软件只读；④ 帧由 `escape` 结束；⑤ 第 5 章单列异步进入/退出专节。`escape` 编码**不变**（保留 `imms18[1]` 帧选择位）。

## 要做

1. **`spec/DADAO-12`**
   - `§1`/`§2`：异常分流表述改为"异步源以 cfxha 标识、统一投 `cfx_hart`"，删"宏 cause 17/18"。
   - `§3.1`–`§3.4`：删除 `<mode>_cfx_intr_mask`（`rc4`）；该段改为"异步来源掩码见 monitor `cg8 rc1`"。
   - `§3.6`：异常原因表删除 `1<<17`/`1<<18` 两行，改为一条"异步源标识（不占 `excp_cause_id`；位 = 源 cfxha）"说明。
   - `§3.9`：整节删除，`cg9` 表移入 `§4.7`。
   - `§4.1`–`§4.4`：monitor 的 `cg8 rc1` 改为 `cfx_<monitor>_async_intr_mask`（位 = 源 cfxha；`0=允许`/`1=屏蔽`；复位全 1）；删除 `trap` 保存/恢复该掩码的表述。
   - `§4.7`：cg9 七槽（`prev_run_mode`/`prev_cfx`/`cause_ip`/`src_frame`(RO)/`src_pending`(RO)/`excp_vector`/`switch_run_mode`；`rc7–15` reserved）；异步入口段改为"一帧多源、无嵌套、mask 在 monitor、source ack 在源 cfx"。
   - `§4.9`：删除"`cause_info` 携带 `dma_status`"；PMEM_DMA 以 cfxha 32 标识，pending 位 `1<<32`。
   - `§5` 新增 **"异步中断进入与退出"** 专节：来源过滤（按当前运行模式取 monitor 掩码）、pending 语义（跟随源事件、投递即清、ack 即落、不计数）、一帧多源（位图并集）、无嵌套、现场字段、`escape` 返回并释放帧、计数；`§5.2`/`§5.3` 只保留同步流程并指向新节。
   - **精确点写死**：异步在指令边界识别；被中断指令已提交（`rb0` 已更新；`call` 已写 `ra63`、`ret` 已弹栈）；`async_cause_ip` = 提交后的 `rb0`（跳转即目标）；`escape` 不重放。
   - 变更记录：一条（内容改，版本仍 `0.8.0-rc`）。
2. **契约**：`contract-see §3/§6.1.1/§6.3/§6.4`、`contract-isa`（`cg9` 字段改名；`escape` 编码不变）、`contract-cfx-aliases`（regname 增删改后重算 `contracts/cfx-aliases.txt`）、`DADAO-22` 变更记录一条（SBI 语义不变）；若 `DADAO-23` 有引用同步改。
3. **不改**：`escape` 编码与工具链、IDL 执行器（`escape` 部分）、任一实现代码。

## 不做

- 不改 `escape`（`imms18[1]`、`{0,1,2}`、`{0,4,8}` 保持）；
- 不改 QEMU/RTL/gem5/kernel（各自修订任务另立）；
- 不升版本号。
