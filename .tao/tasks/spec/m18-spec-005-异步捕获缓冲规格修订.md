## 背景

`ADR-0061` R2 已把异步模型改为：

- `cg9` 是**进入瞬间的捕获缓冲**，每次 async 进入覆盖；硬件不因 `src_frame != 0` 拒绝/只置 pending；无 `frame_valid`、无软件清 `src_frame`；
- 入口流程：异步进 hart → 关中断窗口把 cg9 + GPR 搬到 `task_pt_regs` → 进 `cfx_smon`；smon 是普通系统态，按正常中断屏蔽策略处理，嵌套由软件处理；
- `escape imms18=2` **不再承担异步返回**；cg9 捕获后丢弃，返回走 smon/umon；
- mask 仍归 monitor `cg8 rc1`、源索引 cfxha、一帧多源捕获。

现 `spec/DADAO-12`/`contract-see`（spec-004 后）仍写「帧活动期只 pending / 帧由 escape 结束 / 软件写 0 释放」；另有 `Kaiwu`、`IDL-ISA`、`SimRISC-11`、DDLN C002/C003/C004 等活文档残留旧口径（ISS-527）。
