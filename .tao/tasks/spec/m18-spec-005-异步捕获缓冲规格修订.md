## 背景

`ADR-0061` R2 已把异步模型改为：

- `cg9` 是**进入瞬间的捕获缓冲**，每次 async 进入覆盖；硬件不因 `src_frame != 0` 拒绝/只置 pending；无 `frame_valid`、无软件清 `src_frame`；
- 入口流程：异步进 hart → 关中断窗口把 cg9 + GPR 搬到 `task_pt_regs` → 进 `cfx_smon`；smon 是普通系统态，按正常中断屏蔽策略处理，嵌套由软件处理；
- `escape imms18=2` **不再承担异步返回**；cg9 捕获后丢弃，返回走 smon/umon；
- mask 仍归 monitor `cg8 rc1`、源索引 cfxha、一帧多源捕获。

现 `spec/DADAO-12`/`contract-see`（spec-004 后）仍写「帧活动期只 pending / 帧由 escape 结束 / 软件写 0 释放」；另有 `Kaiwu`、`IDL-ISA`、`SimRISC-11`、DDLN C002/C003/C004 等活文档残留旧口径（ISS-527）。

## 目标

1. `spec/DADAO-12`：`§4.7 cg9` 表/语义、`§5.4` 异步专节、`§5.3`/`§5.1` escape 说明改为 R2：cg9 捕获缓冲、每次覆盖、无 active/valid、smon handoff、系统态嵌套、escape 不用于异步返回；mask/pending/源位不变。
2. `contract-see`：§3/§6.2/§6.3/§6.4 同步；`escape` 的 cg9 语义改为“捕获，不返回”；mask/monitor/源位保持。
3. `DADAO-22`/`DADAO-23` 的异步说明（如引用）同步 R2；不升版本。
4. 旧活文档收尾（ISS-527）：`spec/Kaiwu`、`spec/IDL-ISA`、`spec/SimRISC-11`、`docs/DDLN/C002/C003/C004` 中与 R2 冲突的旧口径；只改活正文，不改历史变更记录。
5. `spec/.manifests.toml` 重算受影响册哈希；版本保持 0.8.0-rc；`contract-*` 版本指针不变。
6. 关闭/更新 `ISS-527` 与 `discussing` 相关项。
