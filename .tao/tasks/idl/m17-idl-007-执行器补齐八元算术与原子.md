## 背景

本组覆盖 64 位算术/位操作与原子/位计数，语义分散在 `SimRISC-04`（八元逻辑、移位、乘除、`cmp`、`ext`）与 `SimRISC-12`（`ctlz`/`cttz`/`ctpop`、`lr`/`sc`、`swym`）。

范围（2026-11-22 实测缺失数；执行时用脚本重算，不采信本文数字）：
- `tests/inst/04-arith-logic-octa`：23 个缺失 id；
- `tests/inst/12-misc`：27 个（`lr.*` 15、`sc.*` 12、`ctlz`/`cttz`/`ctpop`/`swym` 已在其中按现场统计）；
- `tests/inst/00-isa-design/atomic_rmw`（非 id 载体，用 `lr`/`sc` + 算术）。

## 要做

1. 按 `.idl` 正文逐 id 实现；函数上方注明 id 与出处册；
2. 本组镜像从 `pending` 移入主清单，逐例四方零红；
3. 原子语义按 `SimRISC-12 §1`：`lr`/`sc` 的 an/ar/nn/nr 四变体、8/16/32/64 位宽、窄读保留高位、保留清除事件按单 hart 口径；`clmul` 双目的与 `cmp` 三值按 `SimRISC-04`；
4. 位计数按 64 位 `hd` 上界；`swym` 为流水线提示（无架构副作用）。

## 不做

- 不改已通过 id 的语义；不改 `tests/inst`、`.idl` 源、QEMU/gem5/RTL；
- 不做 FP、不做 8/16 位 ALU（`008`）、不碰 `01`/`02`/`05`/`06`/`11` 册（`006`）。
