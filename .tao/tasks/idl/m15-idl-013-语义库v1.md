## 裁定原文（用户 2026-11-19）

- **T1**：`ip()` 为 `Bits<64>`，**高 16 位固定为 0**；跳转类指令的计算结果写回 IP 时**只保留 48 位**。
- **T2**：`set.w` 写 `rf` 用**切片赋值**（`rf[d][hi:lo] = imm`），不新增函数。
- **T3**：`SimRISC-00 §2.3` 改「**专用于**浮点类指令」；不在 `SimRISC-07` 的那些（`set.*`/`ld.t`/`ldm.t`/`rf2rf`/`rd2rf`）是**直接赋值/复制**类，**不牵涉运算**，不受此限。
- **T4**：`SimRISC-03` 的「选中 wyde」规则**在散文里补一句写全**。
- **T5**：补 `inner_cfx_code()` / `cfx_frame_valid(cfxha)` / `cfx_escape_enter(cfxha, imm)`。
- **T6**：补 `cfx_read(cfxha, cg, rc)` / `cfx_write(cfxha, cg, rc, value)`（读写权限由 spec 寄存器表描述，IDL 不做权限判定）。
- **T7**：照 UDB 加 `builtin function cfx_fence(cfxha, pred, succ)`（**无 body**），注释「顺序语义由实现提供，IDL v0 不建模」。
