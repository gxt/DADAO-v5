## 统一语义规则（B4 全 63 条）

### 合法性（**先于任何寄存器读**，不得先读后判）
- `dst_rd0`（63 条）：目的 `rdhb` 为 `rd0` ⇒ ILLI。
- `encode_sbz`（12 条：32/16/8 位各 4 条 `orri` 移位）：`immu6 ≥ W`（32/16/8 位分别 `>31`/`>15`/`>7`）⇒ ILLI。SBZ 是**立即数字段**约束；`orrr` 的 `rdhd` 高位**不**触发 ILLI（取模）。
- `encode_onehot`（3 条：`rev.t/w/b`）：`k` 非 one-hot 或 `k ≥ S`（S=32/16/8）⇒ ILLI；合法集分别为 `{1,2,4,8,16}`/`{1,2,4,8}`/`{1,2,4}`；`k = S` 是恒等档，**不合法**。
- 顺序：静态 ILLI → 计算 → 写目的。B4 无访存、无对齐、无 MALIGN/内存 fault（`RegAccess` 无访存方法，编译期排除）；`executeB4` 若返回 `Malign`/`Memory` 即 `panic`（实现错误）。
- 目的寄存器不得被写入的 ILLI 路径：mock 记录写入次数为 0（与 B2/B3 同口径）。

### 读写顺序与别名
- 先读全部源再写目的；`rdhb == rdhc` 允许原地运算；`rdhc`/`rdhd` 为 `rd0` 读出 0（合法源）。
- 单目的写：只在所有源快照之后写 `rdhb` 一次。

### 宽度语义（B4 的核心）
- **源只取低 W 位**（W=32/16/8），高位一律不参与；先截断再运算，不得先做 64 位运算再截断（对 `div`/`rem`/`cmp` 尤甚）。
- 所有结果**写满 64 位**：`u` 变体零扩展、`s` 变体符号扩展；`cmp` 的 −1 为**64 位全 1**、0/±1 写满 64。
- 加/减/乘：结果按 2^W 取模，溢出静默丢弃；`mul` 只保留乘积低 W 位，再按符号性扩展。
- `div.s`/`rem.s`：C99 截断向零，余数符号 = 被除数符号；`div.u`/`rem.u` 零扩展。
- 除余定值（`contract-isa §6.1.5` 表）：除零 ⇒ `div.u` = `(1<<W)-1` 零扩展、`div.s` = 全 1、`rem.*` = 被除数（按符号性扩展）；有符号溢出 `INT_MIN÷−1` ⇒ `div.s` = `INT_MIN`（按 W 符号扩展，如 32 位 `0xFFFF_FFFF_8000_0000`）、`rem.s` = 0。`rdhd == rd0` 读出 0 ⇒ 除零 ⇒ 走定值（合法，不 ILLI）。

### 移位量
- `orrr`：`shamt = rdhd[log2(W)-1:0]`（32/16/8 位分别取 `[4:0]`/`[3:0]`/`[2:0]`），**天然 mod W**；`rdhd` 高位非零不报错（如 `rdhd=W ⇒ shamt=0`）。
- `orri`：`shamt = immu6`，`0..W-1` 全合法；`immu6 ≥ W` ⇒ ILLI（`encode_sbz`，见上）。
- 依据：`contract-isa §6.4.5`「寄存器形态取模、立即数形态不取模」+ `spec/SimRISC-08/09/10 §2`；`§10.4.1` 表中的「`hd[5]` 应为零」指**立即数字段**，不适用于 `orrr` 的寄存器值。

### rev.t/w/b（3 条）
- 64 位源切成 `64/S` 个 S 位块；每块按 `k` 位切成 `S/k` 个单元，**反转单元顺序**（单元内位序不变），**所有块一律同样处理**，结果写满 64 位。
- `k=8` ⇒ 每块内 `bswap`（`rev.t` 为 bswap32、`rev.w` 为 bswap16）；`k=1` ⇒ **每块内**位反序，不是 64 位整体位反序（`rev.o` 才是整体）。
- 源高块非零时仍按定义处理全部块；spec 的「`k=8` 须源高位置 0」是**使用约定**，不是硬件 ILLI 条件（异常表无此项）。
- `rdhc` 可为 `rd0`（读出 0）；`rdhb == rdhc` 允许原地反转；`rdhb == rd0` ⇒ ILLI。
