## 统一语义规则（B1 全 38 条）

### 地址与端序
- 有效虚拟地址 48 位（`contract-isa §1.5`）；单存取：`EA = (rbhb[47:0] + sext64(imms12)) mod 2^48`。
- 多存取：`EA_i = (rbhb[47:0] + rdhc_original + i*width) mod 2^48`，`i=0..immu6-1`；`rdhc` 取指令原始值，块内写目的不得改变后续地址（`SimRISC-01 §1/§2`）。
- `rb0` 作基址时读出**当前指令地址**（不是下一条）；`rb0` 作源时同（ADR-0012 D1/D4；`contract-isa §1.3.2`）。
- 数据与指令均为大端序（`contract-isa §1.6`）：`st.w` 在 `EA` 放 `[15:8]`、`EA+1` 放 `[7:0]`；`st.t`/`st.o` 依次 `[31:24]…`/`[63:56]…`；load 反向组装。gem5 `readMem`/`writeMem` 按字节数组返回/写入，端序转换在 B1 核内完成。

### 合法性与异常顺序
- 静态非法（先于任何寄存器/内存访问）：
  - `ld.*`/`ldm.*` 的 RD 目的 `rdha==rd0` ⇒ ILLI；RB 目的 `rbha==rb0` ⇒ ILLI；RA 目的 `ra0` 合法；RF 目的 `rf0` 合法。
  - `st.*`/`stm.*` 的 RD/RB 源为 `rd0`/`rb0` 合法（`rd0` 读 0，`rb0` 读当前 IP）；RA 源 `ra0` 合法；RF 源 `rf0` 读完整 64 位。
  - 多存取 `immu6==0` ⇒ ILLI；`start + immu6 > 64` ⇒ ILLI（不环绕、不截断）；B1 只检查目的寄存器起始（`rdhc` 是地址源，不是连续范围）。
- 动态非法：有效地址不满足宽度对齐 ⇒ MALIGN；对齐宽度：`b` 无、`w` 2、`t` 4、`o` 8；RD/RB/RA/RF 同宽度规则。
- 顺序：`ILLI → MALIGN → 内存/TLB fault`；单元素故障不得写目的、不得写内存。多元素中途发生内存 fault 时，已完成的元素是否可见 **spec 未逐字规定**，B1 按 gem5 逐元素访存语义处理并在完成区登记为遗留，不擅自扩为契约。
- 多存取循环：`i` 递增，每对“先读后写”；源/目的范围重叠时按此顺序；地址始终用原始 `rdhc`/`rbhb` 快照。

### RF / FCSR 细节
- `rf0` 是 FCSR：作源读完整 64 位；作目的合法（不同于浮点运算目的）。
- `ld.o`/`ldm.o` 目的为 `rf0`：按 FCSR 写掩码只更新 `[33:32]` 与 `[4:0]`，其余位保持。
- `ld.t`/`ldm.t` 目的为 `rf0`：`contract-fp §11` 只规定 `[63:32]` 不变；矩阵 `ldm.t` 行另注「rf0 目的按 FCSR 写掩码」，与本条字面冲突。**本任务按 `contract-fp §11`（源真源）实现 t 形态低 32 位写入、高 32 位保持**；测试固定该口径，完成区登记矩阵待刷新。若用户裁定 FCSR 全局掩码优先，只改 t 形态两处分支。
- `st.t`/`stm.t` 源 `rf0` 读低 32 位；`st.o`/`stm.o` 源 `rf0` 读完整 64 位。
- RA 为不透明 64 位：`ld.o`/`ldm.o` RA 不做 `[63:48]` 清零或校验（`contract-isa §3.3`）。

## 接口规范

### B1 语义核（纯 C++，不依赖 gem5 头文件）
新建 `src/arch/dadao/exec/b1.hh` / `b1.cc`：

```cpp
namespace gem5::DadaoISA::exec {
enum class Fault { None, NotB1, Illegal, Malign, Memory };
enum class Bank { Rd, Rb, Ra };
class B1Context {
  public:
    virtual uint64_t readInt(Bank bank, unsigned idx) = 0;
    virtual void writeInt(Bank bank, unsigned idx, uint64_t val) = 0;
    virtual uint64_t readFloat(unsigned idx) = 0;
    virtual void writeFloatLow32(unsigned idx, uint32_t val) = 0; // [63:32] 保持
    virtual void writeFloat64(unsigned idx, uint64_t val) = 0;    // 非 rf0 全 64 位
    virtual void writeFcsr(uint64_t raw) = 0;                      // 仅 [33:32]/[4:0]
    virtual uint64_t pc() const = 0;                               // 当前指令地址
    virtual bool readMem(uint64_t addr, unsigned bytes, uint8_t *out) = 0;
    virtual bool writeMem(uint64_t addr, const uint8_t *in, unsigned bytes) = 0;
};
Fault executeB1(const decode::DecodedInst &inst, B1Context &ctx);
}
```

- `executeB1` 只接受 `inst.entry->batch == 1`；否则返回 `NotB1`，不得猜测执行。
- 字段从 `inst.fieldValues[]` + `entry->firstField`/`fieldDesc()` 取；按 38 个 id 显式分派（可按助记符/宽度分组，但覆盖集合必须等于 B1 38 条）。
- 任何 B1 id 未覆盖、字段缺失或未知规则 ⇒ 断言/显式失败，禁止静默成功。

### gem5 适配
- `inst.cc`：`decoded.ok() && entry->batch==1` 时构造 `Gem5B1Context` 调 `executeB1`；`None→NoFault`、`Illegal→IllegalInstruction`、`Malign→MalignInstruction`、`Memory→ctx.memFault()`；非 B1 仍返回 `UnimplementedInstruction`。
- `faults.hh`：新增 `MalignInstruction`（B1 先 panic 报地址/宽度；B6 再接 trap 向量）。
- `Gem5B1Context`：`getReg/setReg(RegId(intRegClass, RdBase/RbBase/RaBase+idx))`；`floatRegClass` 取 rf，`writeFloatLow32`/`writeFloat64`/`writeFcsr` 分别实现低 32 保持高位、非 rf0 全 64 位、rf0 掩码；`rb0` 由 `pc()` 提供、`rd0` 返回 0；`readMem/writeMem` 用 `xc->readMem(..., Request::Flags(0), {})` / `xc->writeMem(...)`，非零 Fault 暂存并在 `Memory` 返回时交回。
- `SConscript` 增加 `Source('exec/b1.cc')`；`b1_test.cc` **不**进 SConscript，只由 `check_b1.py` 编译。
