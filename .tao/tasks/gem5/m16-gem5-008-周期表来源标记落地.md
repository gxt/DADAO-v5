## 目标

1. **provisional 行不进时序模型**：`provenance` 含 `推断` / `未测` / `待实测` 的行，`extraExecLatency` 一律返回 **0**（保留 Timing 本体 1 拍占位），**不得**使用其 `cycles` / `rangeLo` / `rangeHi` / `defaultCycles` / `memCycles` / `hostCycles`。
2. `实测` / `可配` / `设计值` 三类的行为与 `m16-gem5-003/004` **完全一致**（逐类对照仍差异 0）。
3. 增加一条**可失败**的单元断言：provisional 行（例如 `ext.uo`）在 gem5 上的实测拍数为 **1**（占位），而 `实测` 行（例如 `shl.o`）仍是表值。
4. 组件侧：`wuming_cycles.{hh,cc}` 已由架构师重生成（**未提交**），本任务负责 `git commit --amend` 到组件 base+1 并 `make_patch.py gem5` 重导出，使 `check-patch-tree` gem5 段回绿。
