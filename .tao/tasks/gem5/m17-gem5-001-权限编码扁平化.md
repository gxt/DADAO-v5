# m17-gem5-001: gem5 权限编码扁平化（删 `NCFXPERM`/`NONPTW` + `cause_info` 修正）

**模块**：gem5
**项目里程碑**：M17
**依赖**：`m17-spec-001`（ADR-0062 定稿）
**可并行分片**：否
**预估**：2–4 h
**档位**：中改（复核 ≤40 min）
**状态**：已验证

## 背景

`m17-idl-020` 实测：gem5 在 `cfx2rd`/`cfxtrap` 掩码拒绝时同样把 `CFXPERM` 的 `cause_info` 给成**指令编码**（`ISS-469` 正文原称 gem5 正确，已更正）。另按用户 2026-11-24 裁定改扁平位图：PTW 权限/访存故障只置高位位图（`[32..38]`/`[48..56]`），删除 `[39] NCFXPERM`、`[57] NONPTW`，`CFXPERM`/`CFXMEM` 各只保留单一含义。

当前 gem5 实现按 `ADR-0056`（一 cause 占一个 wyde），`m16-gem5-009` 已落地子原因——本任务按 ADR-0062 返工。

## 要做

1. `node_cfx.cc`/`fs_machine.hh` 等：掩码拒绝时 `cause_info` = 触发指令地址；删除 `SubNcfxPerm` 置位；
2. 删除 `SubNonPtw` 置位；
3. PTW 故障（`fs_tlb.cc`/`node_tlb.cc`）改高位位图，父 `CFXPERM`/`CFXMEM`=0；`cause_info` 按 ADR D4；
4. 更新 `checkCauseId` 断言（不再要求 wyde 父 cause；改为「位图恰一位」与互斥规则按 ADR）；
5. 补负例探针（掩码拒绝 `cause_info`、PTW 位图）。

## 不做

- 不改 QEMU/RTL/Linux/spec；不定义 Vast 路由。

## 约束

- 独立 `git worktree`；组件补丁按 `docs/Process-01`；不提交 git；
- 只动 `components/gem5/patches/src/arch/dadao/*`、`components/gem5/{README.md,changelog.md}`、必要测试、本任务书；完成区 ≤30 行。

## 跨里程碑依赖与冲突（2026-11-24 核对）

- **同组件串行**：`m18-gem5-001`（escape frame，待开始）与 M16 异步 gem5 任务同改 `src/arch/dadao`；本任务须在其后 rebase。
- **返工已验证任务**：`m16-gem5-009`（cause-id 子原因）的实现按 `ADR-0056` 落地，本任务改扁平模型后其 `checkCauseId` 与探针需同步返工。
- **M16 期望**：与 QEMU 相同，cfx/权限类用例的 `cause_id` 期望随删 `[39]`/`[57]` 更新。

## 验证

1. 掩码拒绝 `cause_info == excp_cause_ip`（负例红）；
2. `cause_id` 无 `[39]`/`[57]`；PTW 故障按高位位图；
3. **可达 FAIL ≥2 路**（改回编码 / 加回子原因），`cp`+md5 还原回绿；
4. `check-patch-tree` gem5 段 0 problem；`build-gem5` + 相关 L2/L3 rc=0。

## 待裁定/阻塞

- Vast 的 PTW 故障按 ADR-0062 D6 进当前运行模式 monitor、其退出码不承载 PTW；本任务不改路由，版本号不变。
