## 统一语义规则（B3 全 42 条）

### 合法性（**先于任何寄存器读**，不得先读后判）
- `dst_dual_same`（7 条 rrrr：01–07）：`rdha` 与 `rdhb` **同时**为 `rd0` ⇒ ILLI；两者为**同一非 rd0** 寄存器 ⇒ ILLI；其一为 `rd0` 合法（丢弃该半）。
- `dst_rd0`（31 条）：目的 `rdha`/`rdhb` 为 `rd0` ⇒ ILLI。
- `dst_rb0`（4 条：09/10/32/33）：目的 `rbha`/`rbhb` 为 `rb0` ⇒ ILLI。
- `encode_onehot`（42 条）：`immu6` 非 one-hot 或 `≥64` ⇒ ILLI；`rev.o` 合法 `k=1/2/4/8/16/32`。
- `ext.*_orrr`（28/29）：`hd = rdhd` 的**全 64 位值** >63 ⇒ ILLI（不是取低 6 位）；`orri` 形态的 `immu6` 恒 ≤63，无非法值。
- 顺序：静态 ILLI → 计算 → 写目的。B3 无访存、无对齐、无 MALIGN/内存 fault（`RegAccess` 无访存方法，编译期排除）；`executeB3` 若返回 `Malign`/`Memory` 即 `panic`（实现错误）。
- 目的寄存器不得被写入的 ILLI 路径：mock 记录写入次数为 0（与 B2 同口径）。

### 读写顺序与别名
- 先读全部源再写目的（`§6.1.1`/`§6.1.4`/`SimRISC-04 §1.5` 明文）；源与目的别名、`rdha`/`rdhb` 同为源时按**快照值**。
- rrrr 双目的：`rdha` = 高 64 位、`rdhb` = 低 64 位；两次写都在源快照之后。
- 单目的：`add.si_riii_rd`/`add.si_riii_rb` 为原地读改写。

### 立即数与移位量
- `imms18`/`imms12` **符号扩展**；`immu12`/`immu6` **无符号**，不得符号扩展。
- `aip.si`：`(sext(imms18) << 12)` 在 64 位上移位，结果 mod 2^64；`IP = pc()`（**当前指令地址**，不是 IP+4），**低位不清零**；汇编层 `imms30` 按字节，编码层 `imms18` 按 4 KiB 块（本任务只消费编码层字段）。
- 移位量：`orrr` 取 `rdhd[5:0]`（自然 mod 64，如 `rdhd=64 ⇒ 0`、`65 ⇒ 1`）；`orri` 用 `immu6`，`0..63` 全合法。`contract-isa §6.4.1` 的「`shamt > N` ⇒ ILLI」对 64 位**不可达**，不得伪造 ILLI（见「未决问题」2）。

### 值语义
- 所有结果**写满 64 位**（逻辑/移位/比较/位扫描/扩展/rev/div-rem），不存在「高位保留」。
- `cmp.*` 的 −1 必须是 64 位全 1；0/1 写满 64。
- `div.s`/`rem.s`：截断向零（C99），余数符号 = 被除数符号；`div.u`/`rem.u` 零扩展。
- 除余定值（`contract-isa §6.1.5` 表 64 位行）：除零 ⇒ `div.*` 全 1、`rem.*` 被除数；有符号溢出 `INT_MIN÷−1` ⇒ `div.so` `0x8000_0000_0000_0000`、`rem.so` 0。`rdhd == rd0` 读出 0 ⇒ 除零 ⇒ 走定值（合法，不 ILLI）。

### RB 运算（32–35）
- `bbd`：目的 `rbhb`、源 `rbhc` + `rdhd`；`dbb`：目的 `rdhb`、源 `rbhc` + `rbhd`。**按字段角色判银行，不按助记符**（`sub.o` 三个 id 分属 rrrr/bbd/dbb；`cmp.uo` 有 dbb/rd 两个 id）。
- 全 64 位参与、结果完整保留；仅**访存时**取 `[47:0]`——B3 不访存，**不做地址截断**，`[63:48]` 照常写回。
- `rb0` 读出 = 当前 IP（`pc()`）：作源合法、作目的 ILLI。

### rev.o（42 条）
- 定义：64 位源为 1 个 64 位块；按 `k` 位切成 `64/k` 个单元，**反转单元顺序**（单元内位序不变），结果写满 64 位。
- `k=8` ⇒ `bswap64`；`k=1` ⇒ 64 位整体位反序；`k=2/4/16/32` 按定义。
- `rdhc` 可为 `rd0`（读出 0）；`rdhb == rdhc` 允许原地反转；`rdhb == rd0` ⇒ ILLI。

## 与 0628 的对照（只作溯源，不作执行依据）

> 逐条见矩阵同 id 行 `old0628_*`/`reuse_*` 列（`reuse_semantics` 42/42 = 否）。**不得复制代码**。

- `add/sub`：0.4.1 统一按符号扩展 128 位；v5 拆 `.uo`（ZX，高半=进位/借位 0/1）与 `.so`（SX，高半=高 64 位）——**同名不同义**。
- `addi`：0.4.1 为 `rrii` 双操作数、只算低 48 位；v5 `add.si` 为 `riii` 就地加、全 64 位（rb 变体同）。
- `rela`：0.4.1 先把 `rb0` 按 4 KiB 向下对齐并保留 `[63:48]`；v5 `aip.si` 用 IP 原值、整 64 位（ADR-0029 D1）。
- `divu/divs`：0.4.1 同时写商与余数、除零与溢出触发 ILLI；v5 拆 `div`/`rem` 单目的、改定值（用户裁定 2026-10-01）。
- RB `add/sub`：0.4.1 只算低 48 位并保留 `[63:48]`；v5 整 64 位（ADR-0012 D8.7）。`cmp-rb`：0.4.1 只比低 48 位，v5 整 64 位无符号（D8.2）。
- `clmul.o`/`rol.o`/`rev.o`/`ctlz`/`cttz`/`ctpop`：0.4.1 无对应实现（新增），无旧实现可复用。
