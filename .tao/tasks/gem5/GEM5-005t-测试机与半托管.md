## 执行环境

## 接口规范
- 输入：`spec/Machine-01 §1–§7`、`contract-elf.md §1/§5/§6`、`contract-semihosting.md`，现有 boot ROM、ELF 与测试脚本。
- 输出：单核 `AtomicSimpleCPU` 全系统配置；`PT_LOAD` ELF 加载与 boot ROM、唯一 16 MiB RAM、复位 PC、`hypv→user`、异常/`trap`/`escape`；DADAO semihosting 适配层和退出状态传播。
- 约束：使用 `Machine-01` 的地址图、权限和服务号，不另创 guest ABI。semihosting tag 与 `cfxha` 无关；一般 trap 走异常向量，semihosting 短路并前移 PC。`SYS_SYSTEM` 按既有风险约束运行；不以测试便利为由更改规范。

## 验收标准
1. 同一 boot ROM 和 DADAO ELF 在 gem5 从复位向量启动，完成模式移交；错误 ELF 头、越界段与非法访问显式失败。
2. `Machine-01 §5` 的全部 25 服务逐项通过，含 64 位大端参数块、返回寄存器、`SYS_EXIT`/`SYS_EXIT_EXTENDED` 的宿主退出状态。
3. 普通 trap/escape 与 semihosting 两条路径、权限/异常路由均有规范向量；错误服务号或错误参数不会静默成功。
4. 每组门控有反例注入 FAIL→还原 PASS 证据；`make check-modules` 通过。
