## 接口规范

### 1. 统一 dispatcher（唯一分派真源）

新增 `components/gem5/patches/src/arch/dadao/exec/dispatch.hh` + `dispatch.cc`（纯 C++，不依赖 gem5 头）：

```cpp
namespace gem5 { namespace DadaoISA { namespace exec {
/** 前置条件：batch ∈ [1,7]（调用方已用 decoded.entry->batch 校验）。
 *  返回所属批执行核的原始 Fault（含该核自己的 NotBk）。
 *  不在此处把 NotBk 解释为 unimplemented。 */
Fault dispatchBatch(uint8_t batch, const decode::DecodedInst &inst,
                    B7Context &ctx);
}}}
```

- `switch (batch)` 必须**恰好 7 个 case**，`case k` 只调用 `executeBk(inst, ctx)`；`default` 用 `__builtin_unreachable()`（调用方已拦截越界）。
- `B7Context : B6Context : B5Context : B1Context : RegAccess`，因此一个 `B7Context&` 可传给全部 7 个执行核（B2/B3/B4 取 `RegAccess&`，B5/B6/B7 取各自派生类引用）。
- 既有 `executeBk` 均**先判批次再判合法性**（现场核对：`if (!inst.ok() || inst.entry->batch != k) return Fault::NotBk;`），故错批调用零副作用。

### 2. `inst.cc` 改造（行为等价，结构收敛）

- 删除 7 段重复 `if/else + switch`，改为：
  1. `if (!decoded.ok())` → `IllegalInstruction`（不变）；
  2. `const uint8_t batch = decoded.entry->batch; if (batch < 1 || batch > 7)` → `UnimplementedInstruction`（**唯一**一处 `UnimplementedInstruction` 构造，删除函数尾防御性返回）；
  3. `exec::Fault f = exec::dispatchBatch(batch, decoded, ctx);`
  4. `switch (f)`：`None` → `NoFault`；`Illegal`/`Malign`/`Memory`/`RasOverflow`/`RasUnderflow`/`CfxReg`/`CfxEsc` → 现映射（保留 B6 的 cfx panic 与 B5/B7 的 RAS panic 文案）；`default`（任何 `NotBk`）→ **panic「batch k but rejected by executeBk」**。
- 语义零变化：不碰 `exec/b*.cc`、不改 fault 枚举、不改 panic 触发条件。

### 3. 收敛 harness（`exec/converge_test.cc`，standalone）

- 编译方式与 `check_b7.py` 相同：`g++ -std=c++17 -I<src> decode/decode.cc exec/b1..b7.cc exec/fp_soft.cc exec/dispatch.cc exec/converge_test.cc`。
- `TestContext : exec::B7Context`：整数/RF 寄存器数组（全整数寄存器初值 `0x1000`，8 字节对齐）、平坦内存、cfx 小数组（`readCfx`/`writeCfx` 成功）、`trapTo()` no-op、`escapeFrom()` 返回 true、保留标记单槽、`ordering()`/`swymHint()` no-op、`pc()=0x1000`。
- 读入由生成器产出的 `converge_words.inc`（`{id, word, owner_batch}`，264 行），对每条 id 做：
  1. `decodeWord(word)` 成功且 `entry->id == id`、`entry->batch == owner_batch`；
  2. **正路**：`dispatchBatch(owner, ...)` 结果 ∉ {任何 `NotBk`}，且 ≠ `Illegal`（合法字不得静态拒绝）；
  3. **错批矩阵**：对 `k = 1..7, k != owner`，`dispatchBatch(k, ...)` **必须恰好等于** `Fault::NotBk`；且调用前后寄存器/内存/FCSR/保留标记快照逐字节相同（零副作用）；
  4. 每条 id 打印一行 `[PASS] converge-id <id>`；末尾 `summary: ids 264/264, boundary 1848/1848, failures <n>`。
- harness 只做分派/边界/可达性断言；指令值语义仍由 `check_b1..b7.py` 负责，不在此重复 oracle。

### 4. 合法字生成器（`tools/gem5/gen_converge_words.py`）

- 字段名/位段/`value`/`legality`/`rule_refs` **只读 `contracts/opcodes.yaml`**，不读 C++ 执行语义、不读 QEMU/LLVM；`owner_batch` 只读 `tools/gem5/gen_decode_table.py::batch_of()`（批次唯一真源），不手写。输出确定性排序的 `converge_words.inc`（`--out`，默认 `.work/build/gem5/converge_words.inc`）。
- 字段候选值按角色取（示例，不是硬编码结果）：目的 rd/rb/ra/rf ∈ {2,5,6}；源 rd/rb/ra/rf ∈ {2,3,4,5,6}；`immu6`（计数/one-hot/root n）∈ {1,2,4,8,16,32}；地址立即数 `imms12/imms18/imms24` ∈ {0,8,16,32}；`immu18`（fence/escape）∈ {0,1}；`cfxha` ∈ {0,1,15,16,62}。回溯搜索满足 `legality`。
- `legality` 求值：把 `name[hi:lo]` 转成 `bits(name,hi,lo)`，支持 `!= == <= < > + && || !`；`aligned(N)` 视为**运行期约束**（harness 已保证地址对齐），不参与字段搜索；`no_overlap(a,b,n)` 按区间求值。
- 输出前自检：264/264 有解；每条 `word = contract value | Σ(field_value << lo)`；对每条断言其 `legality` 全满足（`aligned` 除外，标注运行期）。无解即 `rc=1` 并列出 id，**不得跳过或按助记符猜值**。
