## 统一语义规则（B5 全 28 条）

### 合法性（**先于任何寄存器/内存访问**，不得先读后判）
- `dst_rd0`（9 条）：`cs.*` 5 条（`cs.n/z/p` 判 `rdhb`、`cs.eq/ne` 判 `rdhc`）+ `rd2rd`/`ra2rd`/`rb2rd`/`rf2rd` 4 条（`rdhb`）⇒ 目的为 `rd0` ⇒ ILLI。**按字段角色判，不按助记符**。
- `dst_rb0`（2 条）：`rb2rb`/`rd2rb` 的目的 `rbhb == rb0` ⇒ ILLI。
- `dst_rd0_nonzero`（1 条）：`ret` 的 `rdha == rd0 && imms18 != 0` ⇒ ILLI；`ret rd0, 0` **合法**（不写返回值）。
- `mreg_zero`（8 条块搬移）：`immu6 == 0` ⇒ ILLI（`immu6` 为 6 位字段，1..63 合法）。
- `mreg_range_overflow`（8 条）：目的起始 + `immu6 > 64` 或源起始 + `immu6 > 64` ⇒ ILLI；**不环绕、不截断**。
- `mreg_range_overlap`（2 条，仅同组 `rd2rd`/`rb2rb`）：源区间与目的区间有任何交集（含完全重合）⇒ ILLI；跨组（rd2ra/ra2rd/rd2rb/rb2rd/rd2rf/rf2rd）**结构性不可能重叠，不检查**。
- 控制流 15 条**无静态合法性**（`rd0`/`rb0` 作源合法；`ret` 例外见上）。
- 顺序：静态 ILLI → RAS 判定（RASOF/RASUF，含 D4b 的 MemRAS 读与内容判定）→ 计算 → 写目的/RA/MemRAS → 跳转。故障路径零写（mock 记录写次数为 0）。

### 块搬移（8 条）
- 按**序号递增逐对处理，每对先读后写**；同组重叠已被静态 ILLI 排除，故不存在读写竞争；跨组天然无重叠。
- 每组元素 64 位**二进制不变**：无符号/零扩展/舍入/标志一概不适用（`fp_env` = 不适用）。
- `ra0` 作源/目的**不触发异常**（含 `RACNT`/`MRPTR` 位域）；块搬移按矩阵 `g1_note`「RA 槽按不透明 64 位传输」（见「未决问题」5）。
- `rd2rf` 目的含 `rf0` 时写 `rf0` 只更新 `[33:32]/[4:0]`（复用 `RegAccess::writeFcsr`）；`rf2rd` 源 `rf0` 读完整 64 位（`readFloat`）。

### 条件赋值（5 条）
- 先读全部源（`rdha`、`rdhc`、`rdhd`，`cs.eq/ne` 另读 `rdhb`）再写目的一次；源与目的别名按**快照值**（0.4.1 记 OPEN，v5 明确）。
- `cs.n/cs.p` 用**有符号** 64 位判据（bit63）；`cs.z` 判全 64 位为零；`cs.eq/ne` 整 64 位相等。
- 条件不成立时写回原值（不是不写）；目的只写一次。

### 控制流地址（15 条）
- **rb0 是 64 位寄存器**，读出 = 当前正在执行的指令地址（IP，非 IP+4）；`rb0` 作显式目的 ⇒ ILLI（本批无此类目的）。
- 地址计算按 **64 位全宽**：`iiii` = `rb0 + (sext(imms24)<<2)`；`riii` = `rb0 + (sext(imms18)<<2)`；`rrii` = `rbha + rdhb + (sext(imms12)<<2)`（`rbha` 仅读）；结果写回 `rb0`，下一条地址取 `rb0[47:0]`。
- 立即数一律**符号扩展后左移 2**（`sext` 后 `<<2` 在 64 位上取模 2^64）；不得按 48 位算术、不得清零 `rb0[63:48]`（0.4.1 做法，已否决）。
- 条件不成立/顺序执行：`IP = rb0 + 4`（64 位）。
- **本任务不新增 IALIGN 判定**：矩阵 `exceptions` 对 15 条均为「无」；`rrii` 目标未 4 对齐属取指异常（`spec/SimRISC-00 §3`），由取指/PC 机制承担（见「未决问题」4）。
- 48 位截断口径：按 ADR-0012 D8.3/D8.7「取指/跳转目标取低 48」，实现与 QEMU 已验证模型一致——**模型内 PC/rb0 按 64 位保存，48 位截断由地址空间（TLB/取指）承担**；harness 断言完整 64 位目标（见「未决问题」1）。

### RAS（RegRAS + MemRAS，`call`/`ret`）
- `ra0`：`[63:54]` SBZ（RAS 硬件写时**保持原值**）、`[53:48]` = `RACNT`（0–63）、`[47:0]` = `MRPTR`（8 字节对齐，0 = 未启用 MemRAS）。
- `ra1`–`ra63`：`[63:48]` 递归计数、`[47:0]` 返回地址；`ra63` 恒为栈顶；有效条目 = 自 `ra63` 起向下连续 `RACNT` 个（栈底 = `ra[64−RACNT]`）。
- 压栈（`call`），判定顺序 C1 → C2 → C3a/C3b：
  - C1 `RACNT==0`：新条目（计数 1、返回地址）入 `ra63`，`RACNT=1`。
  - C2 `RACNT>0` 且 `返回地址 == ra63[47:0]` 且 `ra63[63:48] < 0xFFFF`：`ra63[63:48] += 1`，`RACNT` 不变（递归折叠，不搬移）。
  - C3a `RACNT<63`：有效条目整体下移一格（`ra[i+1]=ra[i]`，i 从 63 递减），新条目入 `ra63`，`RACNT+=1`。
  - C3b `RACNT==63`：① `MRPTR==0` ⇒ **RASOF**；② `MRPTR−=8` 并把**栈底** `ra[64−RACNT]`（`=ra1`）写入 `MRPTR` 处（8 字节大端）；③ 有效条目下移一格 + 新条目入 `ra63`，`RACNT` 保持 63。
  - 返回地址 = **`pc() + 4`**（相对/绝对一致），存 `[47:0]`（取低 48）。
- 弹栈（`ret`）：
  - D1 `RACNT>0` 且 `ra63[63:48]==0` ⇒ **RASUF**。
  - D2 `RACNT>0` 且 `ra63[63:48]>1`：计数 −1，`RACNT` 不变，`IP = ra63[47:0]`。
  - D3 `RACNT>0` 且 `ra63[63:48]==1`：弹出栈顶（有效条目上移一格，`ra[i]=ra[i+1]` 递增），`RACNT−1`，`IP = 弹出条目[47:0]`。
  - D4a `RACNT==0` 且 `MRPTR==0` ⇒ **RASUF**。
  - D4b `RACNT==0` 且 `MRPTR!=0`：读 `MRPTR` 处 8 字节（大端，`MRPTR` 暂不修改）→ 计数 0 ⇒ **RASUF**；计数 1 ⇒ `IP = 条目[47:0]`、`MRPTR+=8`、`RACNT` 保持 0；计数 >1 ⇒ 条目（计数 −1）入 `ra63`、`RACNT=1`、`MRPTR+=8`、`IP = 条目[47:0]`。
  - MemRAS 容量耗尽**不由硬件检测**（交 OS，ADR-0012 D7 §7）。
- **精确异常**：RASOF/RASUF/内存 fault 时 RA 寄存器与内存均保持异常前状态，IP 指向本 `call`/`ret`，`ret` 的 `rdha` 不写。压栈路径必须先完成判定再提交；C3b 的 MemRAS 写失败时 `MRPTR`、`RACNT`、`ra_i` 全部不变。
- RegRAS 在 gem5 中以真实 `ra` 寄存器为架构视图 ⇒ **显式搬移**（不使用隐藏基准索引）；代价 O(63) 次寄存器写，属正确性优先的取舍（ADR-0012 D7 §5 允许环形缓冲，但 `ra_i` 软件可见，搬移更简单且无别名风险）。

## 与 0628 的对照（只作溯源，不作执行依据）

> 逐条见矩阵同 id 行 `old0628_*`/`reuse_*` 列（`reuse_semantics` 28/28 = 否）。**不得复制代码**。

- **编码位被重新指派**（按编码搬运必错）：`cs.p` 0x64（0.4.1 = `jump`）、`cs.ne` 0x67（= `ldmo-ra`）、`br.p`/`br.np` 0x6C/0x6D（= `call`）、`br.eq` 0x6E（= `ret`）、`br.ne` 0x6F（= `stmo-ra`）、`br.z/nz`-rb 0x72/0x73（= `cfx2rd`/`cfx2rc`）、`ret` 0x76（= `trap`）。
- **控制流地址**：0.4.1 用 48 位算术并保持 `PC[63:48]=0`；v5 全 64 位计算、写回 `rb0` 后取低 48（ADR-0012 D8.3）——同名不同义。
- **RAS**：0.4.1 用 `ra1[63:48]≠0` 判满、逐条搬移、**无 MemRAS**；v5 用 `RACNT`/`MRPTR` + C1–C3b（含递归折叠与 MemRAS 换出），返回地址 = IP+4 —— 不可复用。
- **rd2rd 重叠**：0.4.1 记为 OPEN（按序先读后写），v5 明确 **ILLI**；`rd2ra`/`ra2rd`/`rb2rb`/`rd2rb`/`rb2rd` 矩阵 `old0628_identity` = 同义，但仍 `reuse=否`（编码已迁移、须按当前 spec 重导）；`rd2rf`/`rf2rd` 旧表未覆盖（0.4.1 无 FP）。
- `cs.*` 的「源=目的重叠」在 0.4.1 为 OPEN，v5 明确「先读全部源再写」。

- **ret**：D1（栈顶计数 0 ⇒ RASUF）；D2（计数 >1 ⇒ 递减、`RACNT` 不变、`IP=ra63[47:0]`）；D3（计数 1 ⇒ 出栈、`RACNT−1`、后续条目上移、`IP=弹出[47:0]`）；D4a（`RACNT=0`、`MRPTR=0` ⇒ RASUF）；D4b 三支（条目计数 0 ⇒ RASUF 且 `MRPTR` 不变；1 ⇒ `IP=条目低 48`、`MRPTR+8`、`RACNT=0`；>1 ⇒ 入 `ra63` 计数 −1、`RACNT=1`、`MRPTR+8`）；`rdha = sext(imms18)`；`ret rd0, 0` 合法且零写；`ret rd0, 1` ⇒ ILLI 且**读/写次数均为 0**。
- **精确异常**：C3b 注入 MemRAS 写失败 ⇒ `Memory`，`MRPTR`/`RACNT`/`ra_i` 全不变；D4b 注入读失败 ⇒ `Memory`，RA 不变；RASOF/RASUF ⇒ `rdha` 不写、`ra`/内存零写、`pc` 不变（IP 指向本指令）。
- **规则/引用**：28 条的 `rule_refs`（9/2/1/8/8/2）与 `contracts/opcodes.yaml` 同 id 一致；未知 rule id、缺失 `spec_cite` ⇒ FAIL。
