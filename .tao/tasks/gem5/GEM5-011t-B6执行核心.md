## 统一语义规则（B6 全 30 条）

### 判定顺序（**静态先于一切访存/寄存器访问**）
静态 ILLI → MALIGN → 运行期（CFXREG / CFXESC）→ 访存 → 提交。任何故障路径**零写**（rd/rdHB/内存/保留标记，mock 记录写次数 = 0）。

- 静态 ILLI（本批 5 类）：
  - `cfxha` 为保留编号（6–14、19–61）⇒ ILLI：`trap`/`escape`/`cfx2rd`/`cfx2rc`/`fence`（5 条）；
  - `escape` 的 `imms18[17:1] != 0` ⇒ ILLI；
  - `fence` 的 `hb = immu18[17:12] != 0` ⇒ ILLI；
  - `sc.*` 的 `rdHB == rd0` ⇒ ILLI（12 条，`dst_rd0`）；
  - `lr.*` 的 `hb(rdHB) != rd0` ⇒ ILLI（12 条）。**依据 = `contracts/opcodes.yaml` 同 id 记录（`legality: rdhb == rd0`、`rule_refs: encode_sbz`）+ 矩阵同 id 行 `exceptions` + `spec/SimRISC-12 §1.1` + `contract-isa §14.2`（SPEC-182t F1 已收口）。**
- MALIGN（本批 24 条中的非 `.b`）：`addr % W != 0`（`W` = 1/2/4/8）⇒ MALIGN；`lr` 不写 `rdHC`、不置标记；`sc` 不写 `rdHB`、不动保留标记、不写内存。
- 运行期：`cfx2rd/cfx2rc` 的 CFXREG（§13.6，不在译码期抛）；`escape` 的 CFXESC（帧/目标错误）。
- 精确异常（§15.2 同口径）：`sc` 的**条件失败**（`rdHB=1`）是**正常完成**，不是异常；只有 MALIGN / 访存 fault 才走精确异常路径。

### 保留标记（`lr`/`sc`）
- **单槽**（每 hart 一个保留）：`(valid, addr, width)`；新 `lr` 覆盖旧标记（spec：本 hart 执行另一条 `lr` ⇒ 清标记）。
- **匹配 = 精确地址 AND 相同访问宽度**（F8.1）；**不按 cache line 扩大**，不同地址/不同宽度不匹配、也不清除（除本 hart 新 `lr` / 本 hart `sc` 完成 / 异常入口）。
- `sc` 完成（成功或条件失败）后**必然**清空本 hart 全部保留标记；`sc` 因 MALIGN/访存 fault 未完成时**不清**（精确异常，未提交）。
- `sc` 允许偶发失败（spurious failure），软件重试；模型不得为追求"总成功"而跳过标记判定。
- 异常/中断入口清标记由平台在异常入口调用 `clearReservations()` 完成；B6 只提供接口与单测（异常模型未落地的边界见「未决问题 5」）。

### 访存与端序
- `lr`/`sc` 复用 `B1Context::readMem/writeMem` 的**字节数组**接口（大端转换在 B1 核心内，B6 不重复实现端序）；B6 只负责宽度 `W` 的取值/写回：
  - `lr`：读 `W` 字节 → **零扩展**到 64 位写 `rdHC`（不做符号扩展，不保留高位）；
  - `sc`：取 `rdHC` 低 `W` 字节写入内存（`.o` 写满 64 位、`.t` 低 32、`.w` 低 16、`.b` 低 8）。
- 顺序属性：`an` ⇒ acquire，`nr` ⇒ release，`ar` ⇒ 两者；`nn` ⇒ 无。经 `readMemOrdered/writeMemOrdered` 传给平台（适配层映射 `Request::ACQUIRE`/`RELEASE`），核心不自行插入屏障。
- `rb0` 作 base 读出**当前 IP**（复用 `RegAccess` 既有语义）；`rdHC = rd0` 作源读出 0（合法）。

### cfx 访问与 trap/escape
- `cfx2rd/cfx2rc` 只做：字段取名（`cfxha`/`cghb`/`rchc`/`rdhd`）→ 保留 cfx 判定 → `readCfx`/`writeCfx` → 精确写回（`cfx2rd` 成功才写 `rdHD`；`cfx2rc` 成功才写 cfx）。
- `trap`：字段取名 → 保留 cfx 判定 → `trapTo(cfxha, immu18)`（控制转移由平台完成，核心不写任何寄存器）。
- `escape`：`imms18[17:1]` SBZ 判定 → 保留 cfx 判定 → `escapeFrom(cfxha, byteOffset)`（字节偏移 = `imms18 << 2`，仅 0/4；返回 false ⇒ CFXESC）。
- 核心**不建模** cfx 寄存器内容、权限矩阵、异常帧与运行模式（平台职责，见「接口规范 3」与「未决问题 2」）。
