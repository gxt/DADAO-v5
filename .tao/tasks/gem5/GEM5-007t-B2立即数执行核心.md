## 统一语义规则（B2 全 8 条）

### 编码与字段（解码由 B0 完成，B2 只消费）
- `rwii`（isa §2.3）：`wpN` 在 `hb[5:4]`；`immu16` = `hb[3:0] << 12 | hc[5:0] << 6 | hd[5:0]`（hb→hc→hd 高位到低位）。字段名/位段以 `contracts/opcodes.yaml` 同 id 记录为准，B2 从解码结果的 `fieldValues[]` + `fieldDesc()` 取，不重算掩码。
- `wpN` 编码（isa §2.4）：`00=wp0 [15:0]`、`01=wp1 [31:16]`、`10=wp2 [47:32]`、`11=wp3 [63:48]`。
- `immu16` 为**无符号** 16 位（8 条 `signed: false`）；不得做符号扩展。

### 逐条语义（掩码形式，全 64 位寄存器）
- 令 `lane = (uint64_t)0xFFFF << (16 * wp)`，`imm = (uint64_t)immu16 << (16 * wp)`：
  - `or.w`：`new = (old & ~lane) | (old & lane) | imm` ⇒ 等价 `new = old | imm`（lane 外恒 0，故与 `old` 或等价；实现用 `(old & ~lane) | ((old >> 16*wp | immu16) & 0xFFFF) << 16*wp` 亦可，断言按语义比对）。
  - `andn.w`：`new = (old & ~lane) | (((old >> 16*wp) & ~immu16 & 0xFFFF) << 16*wp)`。
  - `set.zw`：`new = imm`（其余 48 位为 0，**不保留 old**）。
  - `set.ow`：`new = ~lane | imm`（其余 48 位全 1）。
  - `set.w`（非 rf0）：`new = (old & ~lane) | imm`（其余 48 位保持）。
- 写入宽度：全部 64 位；RD/RB 的 `bits[63:48]` 正常写入（RB 不得清高 16 位，isa §5.2）。

### 合法性与异常顺序
- 静态非法（**先于任何寄存器读**，不得先读后判）：01/02/05/06 的 `rdha==rd0`、03/04/07 的 `rbha==rb0` ⇒ ILLI；`rd0`/`rb0` 必须**不被写入**（写路径上加 panic 兜底，与 B1 同口径）。
- B2 无动态非法、无内存访问、无对齐、无 MALIGN；除上述 ILLI 外不产生异常（ISA 层）。`executeB2` 只要收到 8 条之一就必须给出确定结果，禁止返回 `NotB2` 或静默不写。

### RF / FCSR 细节（仅 08 条）
- `set.w` 目的非 `rf0`：读旧值 → 换 lane → 写回全 64 位（保留其余 48 位）。
- 目的 `rf0`：按 FCSR 写掩码（isa §1.3.3、fp §13、SimRISC-03 §1 注）：
  - `wp2`：`[33:32] ← immu16[1:0]`（`[47:32]` 中仅这两比特可写），其余位保持；
  - `wp0`：`[4:0] ← immu16[4:0]`，其余位保持；
  - `wp1`/`wp3`：**完全写无效**，寄存器内容不变（不得把 16 位整段写进 `rf0`）。
- `rf0` 只读位（`[63:51]`/`[31:22]` Quiet NaN、SBZ）必须保持；禁止用全 64 位写覆盖。

## 接口规范

### 1) 新增共享头 `src/arch/dadao/exec/common.hh`（纯 C++，无 gem5 头）
把 B1 内已有的 `Fault`/`Bank` 上移为批次共享，并抽出 B2 所需的寄存器访问基类；B1 语义零变化：

```cpp
namespace gem5 { namespace DadaoISA { namespace exec {
enum class Fault { None, NotB1, NotB2, Illegal, Malign, Memory };   // 追加 NotB2
enum class Bank { Rd, Rb, Ra };
/** 目的寄存器组（B1Spec/B2Spec 共用；B1 从 b1.hh 移入本文件）。 */
enum class Target : uint8_t { Rd, Rb, Ra, Rf };

class RegAccess {                    // 8 条 B2 只用这 5 个 + pc()
  public:
    virtual ~RegAccess() = default;
    virtual uint64_t readInt(Bank bank, unsigned idx) = 0;
    virtual void writeInt(Bank bank, unsigned idx, uint64_t val) = 0;
    virtual uint64_t readFloat(unsigned idx) = 0;
    virtual void writeFloat64(unsigned idx, uint64_t val) = 0;
    virtual void writeFcsr(uint64_t raw) = 0;   // 仅 [33:32]/[4:0] 可写

/** rwii 字段取值：name -> 值；未知字段返回 false（调用方必须 FAIL）。 */
```

- wyde：8 条各覆盖 `wp0/wp1/wp2/wp3`；`set.zw` 校验其余 48 位为 0、`set.ow` 校验其余 48 位全 1（含 `bits[63:48]`）、`or.w`/`andn.w`/`set.w` 校验其余 48 位保持（old 取非平凡图案，如 `0xDEADBEEF_CAFEBABE`）。
- 立即数分片：`immu16` 取 `0x0000`、`0xFFFF`、`0x0F0F`（hb 高 4 位全 1）、`0xF0F0`（hd/hc 全 1）、`0x8000`（最高位，验证**不**做符号扩展）——分片错误只能在这些值上暴露。
- ILLI：01/02/05/06 目的 `rd0`、03/04/07 目的 `rb0` ⇒ `Illegal` 且寄存器未被写入（mock 记录写入次数）；反例：目的 `rd63`/`rb63` 合法；`set.w` 目的 `rf0` 合法。
- RF/FCSR（08 条）：非 `rf0` 目的保留高 48 位；`rf0` 目的 `wp2` 只改 `[33:32]`（`immu16=0xFFFF` 时 `[33:32]=0b11`、`[47:34]` 不变）、`wp0` 只改 `[4:0]`、`wp1`/`wp3` 内容完全不变；只读 Quiet NaN/SBZ 位不变。
- 规则/引用：8 条的 `rule_refs`（`dst_rd0`×4、`dst_rb0`×3）必须被消费且与 `contracts/opcodes.yaml` 同 id 一致；`set.w_rwii_rf` 的 `rule_refs` 为空必须为空；未知 rule id、缺失 `spec_cite`、矩阵 `semantics` 与实现语义不一致 ⇒ FAIL。
- 无副作用：B2 只经 `RegAccess` 访问寄存器（该接口**无**访存/MALIGN 方法，编译期即排除访存路径）；mock 记录每次 `writeInt`/`writeFloat64`/`writeFcsr`，断言每条用例**只写目的寄存器一次**（ILLI 用例写 0 次）、不写其它寄存器；08 条 `wp1`/`wp3` 的 `rf0` 用例写调用 0 次。
