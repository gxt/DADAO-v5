# m17-qemu-001: QEMU 权限编码扁平化（删 `NCFXPERM`/`NONPTW` + `cause_info` 修正）

**模块**：qemu
**项目里程碑**：M17
**依赖**：`m17-spec-001`（ADR-0062 定稿）；实现口径以 ADR 为准
**可并行分片**：否
**预估**：2–4 h
**档位**：中改（复核 ≤40 min）
**状态**：待开始

## 背景

`ISS-469`：QEMU 在 `cfx2rd`/`cfxtrap` 被来源掩码拒绝时，`CFXPERM` 的 `cause_info` 给**指令编码**，契约要求 = **触发指令地址**（与 `excp_cause_ip` 同值）。`m17-idl-020` 实测 **gem5 同样给编码**（已扩 issue）。另按用户 2026-11-24 裁定，异常编码改扁平位图：

- PTW 权限拒绝只置 `[32..38]`、`CFXPERM`=0；PTW 访存/页缺失只置 `[48..56]`、`CFXMEM`=0；
- 删除 `[39] NCFXPERM`、`[57] NONPTW`；
- `CFXPERM` 只表示 cfx 掩码拒绝；`CFXMEM` 只表示非 PTW 核内访存故障。

## 要做

1. `helper.c` 的 cfx 掩码拒绝路径：`CFXPERM` 的 `cause_info` 改为**触发指令地址**；删除 `DADAO_SUB_NCFXPERM` 的置位；
2. 删除 `DADAO_SUB_NONPTW` 的置位（`CFXMEM` 不再带子原因）；
3. 按 ADR-0062 改 PTW 故障编码：权限/缺失/ADWBFAIL 走高位位图，**父 `CFXPERM`/`CFXMEM` 为 0**；`cause_info` 按 ADR D4；
4. 补负例探针：掩码拒绝时断言 `cause_info == excp_cause_ip`；PTW 故障按高位位图断言；
5. **Vast 的 monitor 路由/退出码**按 ADR 的「未定」处理：若 ADR 未定，先只改 Tiny 可见路径并注明。

## 不做

- 不改 gem5/chipyard/RTL/Linux；不改 spec/contract；
- 不自行定义 Vast 的 monitor 路由与退出码。
