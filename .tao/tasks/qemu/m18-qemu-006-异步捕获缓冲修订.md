## 背景

`m18-qemu-005` 按 ADR-0061 旧版实现「帧活动期只置 pending、`escape` 结束帧、`src_frame != 0` 防重入」。ADR-0061 R2 改为：

- `cg9` 只是进入瞬间的捕获缓冲，每次 async 进入**覆盖**；硬件不因 `src_frame != 0` 拒绝/只置 pending；无 `frame_valid`、无软件清 `src_frame`；
- `escape imms18=2` 不再异步返回；cg9 捕获后丢弃，返回走 smon/umon；
- 入口/嵌套由软件处理；mask 仍归 monitor `cg8 rc1`。

## 目标

1. 仲裁：只要 monitor mask 允许，源事件即进入 `cfx_hart` 并覆盖 cg9；删除 `src_frame != 0 ⇒ 只置 pending` 的 gating。
2. cg9 七槽保持；`src_frame/src_pending` HW/RO（只读信息）；无 valid/clear；`prev_*`/cause_ip RW。
3. `escape imms18=2` 保留编码，但不再作为异步返回；cg9 不参与 sync escape；若 QEMU 有 async-return 分派，移除/改为 sync 路径。
4. pending：只由 monitor mask 屏蔽时置位；解除后进入；源 ack 落位；同界多源一次捕获。
5. 更新 `min_rom_probe_integ051t` 与探针（去掉防重入/escape 返回断言，改“每次覆盖/软件搬运”）；`vast-arch-inventory`/changelog。
6. M16 cfx5/cache 回归不回归。

## 验收（逐条贴真实 rc）

1. `run.sh`：源进入即覆盖 cg9（连续两次 async 第二次覆盖第一次，无 pending 阻塞）；mask 屏蔽时 pending；解除后进入；同界多源 `src_frame` 并集。
2. `imms18=2` 不再返回异步帧（若执行，按 spec 语义报错/不改变 cg9）；sync escape 正常。
3. **可达 FAIL ≥2 路**：① 恢复旧 gating ⇒ 覆盖用例红；② 把 `src_frame` 当有效位 ⇒ 红；还原回绿。
4. 不回归：M16 cfx5/cache、`check-patch-tree` qemu 段 0 problem、`check-component-changelog`、`check-knowledge-refs`。
5. 完成区 ≤30 行；状态 → `待验收`。
