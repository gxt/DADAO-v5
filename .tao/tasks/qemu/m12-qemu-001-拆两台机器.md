# m12-qemu-001: QEMU 拆两台机器 `dadao-tiny` / `dadao-vast`

**模块**：qemu
**项目里程碑**：M12
**类型**：task
**状态**：待开始

## 背景

现状是「一台机器 + profile 属性」：`-machine dadao-m1,profile=tiny|node`。用户裁定拆成两台机器：`dadao-tiny` / `dadao-vast`，并去掉 `profile=`（避免双入口）。

## 目标

1. `components/qemu/patches/hw/dadao/dadao-machine.c.patch`（及 `target/dadao/{cpu.h,cpu.c}.patch` 若涉及）：
   - 注册两个 machine：`dadao-tiny`、`dadao-vast`，几何与能力取对应常量
   - 移除 `profile` 属性；内部选择不再依赖 `profile=` 或环境变量
   - **保留 `dadao-m1` 作为过渡别名**（等同 `dadao-tiny`，`profile=node` 映射到 vast），使后续测试迁移期间每个提交 L1 保持绿
2. 文档：`components/qemu/{README,changelog}.md` 记录三台机器并存与别名移除计划
3. 构建与冒烟：`build-qemu`、`make install-host`；用新机器名各跑一个最小程序（Tiny path B：`-bios` + `-kernel`；Vast 用其 bootrom 镜像）

## 验收标准

1. `qemu-system-dadao -M help` 列出 `dadao-tiny`、`dadao-vast`（`dadao-m1` 仍在，标注 deprecated）
2. Tiny 冒烟：`-M dadao-tiny -bios <tiny bootrom> -kernel <raw>` 退出码与 `-M dadao-m1,profile=tiny` 一致
3. Vast 冒烟：`-M dadao-vast` 与 `-M dadao-m1,profile=vast` 行为一致（同一镜像、同一退出码）
4. `build-qemu`、`install-host`（安装根与构建树 md5 一致）、`check-arch`、`check-inst`、`check-source-state`、L2 rc=0
5. `make check`（L1）rc=0（测试尚未迁移，别名保证不红）
6. 完成区 ≤30 行、无运行期路径
