## 背景

`m12-integ-002 内` 曾建过 `.tao/archive/M12/README.md`，但只放一个文件会让 `check-archive` 报 **7 条违规**（缺任务清单模块计数、终局证据、任务流水、MEMORY 摘录；归档内无任务书）。当时按"不放宽门控"撤回，遗留为待办。本任务按 `docs/Process-04-里程碑归档规范.md` 做**完整归档**。

## 目标（对齐 `check_archive.py` 八条规则）

1. **搬迁**：把 `**项目里程碑**：M12` 的 **41 册**任务书从 `.tao/tasks/<module>/` 搬到 `.tao/archive/M12/<module>/`（模块子目录只允许 `gem5/infra/integ/llvm/qemu/spec/testcases`；本批涉及 `chipyard`/`linux` 等**不在白名单**的模块 ⇒ 先查 `MODULES` 常量，必要时在 README 里说明并**不要**自造目录名，冲突时停下写「待裁定」）。
2. **三件套**（对齐 `M11` 形态）：
   - `README.md`：§1 任务清单（按模块计数，**现场统计**）+ §2 任务流水（冻结表，ID 集合 == 模块册集合）+ §3 终局证据 + §4 MEMORY 摘录 + §5 指针；
   - `m12-retrospective.md`：M12 回顾（做成了什么 / 关键缺陷与修复 / 判据演进 / 遗留）；
   - `issues-closed.md`：M12 期间关闭的 issue 快照（含 `ISS-<数字>`）。
3. **册字段**：每册 `**状态**` ∈ {`已验证`,`里程碑`}；`**项目里程碑**` 写裸 `M12`（尾随括注按编号判、不算错）。

## 验收（逐条贴真实 rc）

1. `python3 tools/infra/check_archive.py` **rc=0**（八条规则全过；贴现场计数：模块 × 册数）；
2. `check-milestones-fresh` 对四个台账全 rc=0（M12 行仍在「已验证」表；册已归档 ⇒ 归档册豁免）；
3. `check-knowledge-refs`、`check-dirs`、`check-no-residue`、`check-archive` rc=0；
4. **≥2 路可达 FAIL 注入**（`cp`+md5 还原）：① 删 `README.md` 里某个模块计数行 ⇒ `check-archive` 红；② 改某册 `**项目里程碑**` 为 `M11` ⇒ 红；
5. 搬迁**不改内容**：每册搬移后 md5 与搬前**逐册相等**（贴对账）；
6. 完成区 ≤30 行、无运行期路径；`**状态**` → `待验收`；不改其它台账行、不改任务书正文。
