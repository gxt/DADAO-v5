## 统一语义规则（B7 全 55 条）

### 判定顺序与故障

**静态 ILLI 先于一切寄存器读**：任一静态检查失败 ⇒ 立即 ILLI，**零读零写**（harness 计读/写次数 = 0）。检查项（按 id 组合，集合与 `opcodes.yaml` 一致）：`dst_rf0`（41）、`dst_rd0`（14）、`mreg_zero`（22）、`mreg_range_overflow`（22）、`mreg_range_overlap`（4）、`encode_fp_root_n`（2）、`encode_onehot`（2）。检查之间无优先级语义（都返回 ILLI），但实现必须**先全部检查、后读源**。

- 无 MALIGN、无访存、无精确异常、无运行期故障；`executeB7` 除 `Illegal`（静态）与 `NotB7`（批次不匹配）外不得返回任何其它 Fault（`Memory`/`Malign`/`Ras*`/`Cfx*` 一律视为内部矛盾 ⇒ panic）。
- 浮点指令**不触发陷阱**：所有 IEEE 异常只累积到 `rf0[4:0]`。

### 寄存器读写与宽度

- **字段按名取**（`fieldValue`），不得按助记符/位置猜；`ftsclb`/`fosclb` 的第三源是 `rdhd`（rd 组，signed 64），不是 `rfhd`。
- **ft**：源取 `readFloat(idx)[31:0]`；结果用 `writeFloatLow32(idx, val)`（**保留 `[63:32]`**，与 B1 `ld.t` 一致）。spec 对 ft 高 32 位「不做特殊规定」，此为本模型的确定性选择，须在 README/changelog 写明「模型选择，非 spec 断言」（未决 7）。
- **fo**：源取完整 64 位；结果 `writeFloat64`。
- `rf0` 作**源**：读出完整 64 位 FCSR 字（其 `[63:51]`/`[31:22]` 已是 qNaN 位型）；作**目的** ⇒ ILLI（41 条）。
- `rd0` 作源 ⇒ 0；`rd0` 作目的 ⇒ ILLI（14 条）。
- **块形式**（convert_ff/classify/f2i/i2f）：`immu6` = 连续个数（1–63），按序号递增**逐对先读后写**；`convert_ff` 额外要求源/目的区间无交集；其余跨组（rf↔rd）结构性不重叠，但仍须检查两侧 `start+immu6 <= 64`。
- 目的允许与源重叠（`orrr`/`rrrr` 单目的）：先读全部源、后写结果。

### FCSR、舍入与标志

- 舍入模式 = `rf0[33:32]`：`00` RNE、`01` RTZ、`10` RDN、`11` RUP。所有算术/转换/开方/sclb/fma 使用该模式；`roundint` 的 5 个静态档**忽略**该模式，仅 `0x20` 读取。
- 标志位 `rf0[4:0]`：bit0 NV、bit1 DZ、bit2 OF、bit3 UF、bit4 NX；**sticky**（只置不清，软件清零）。实现：`accrueFlags(f)` 仅当 `f != 0` 时 `writeFcsr(readFloat(0) | (f & 0x1F))`（`writeFcsr` 只改 `[33:32]`/`[4:0]`）；**不得写回其它位**，**不得清既有标志**。
- `UF` 仅当结果 **tiny 且 inexact**（tininess 检测点 = **舍入后**）；`UF ⇒ NX`，反向不成立；`NX` 与 `UF` 独立。
- 各族标志集合（超出即为实现错误）：

| 族 | NV | DZ | OF | UF | NX |
| --- | --- | --- | --- | --- | --- |
| arith add/sub/mul/div | 有 | 仅 div | 有 | 有 | 有 |
| rem | 有 | 无 | 无 | 无 | 无 |
| sclb | 有（sNaN） | 无 | 有 | 有 | 有 |
| root | 有（负数/sNaN） | 无 | 无 | 无 | 有 |
| fma | 有 | 无 | 有 | 有 | 至多一次 |
| convert_ff | 有（sNaN） | 无 | 有（fo→ft） | 有（fo→ft） | 有（fo→ft） |
| convert_f2i | 有（NaN/Inf/超范围） | 无 | 无 | 无 | 有（有限 inexact） |
| convert_i2f | 无 | 无 | 无 | 无 | 有（inexact） |
| roundint | 有（sNaN） | 无 | 无 | 无 | 仅 `0x20` 且结果≠输入 |
| minmax | 有（sNaN 作输入） | 无 | 无 | 无 | 无 |
| sign / classify / cs_rf | 无 | 无 | 无 | 无 | 无 |
| compare | 见未决 3（默认无） | 无 | 无 | 无 | 无 |

### NaN / Inf / ±0

- **sNaN 作算术输入** ⇒ 置 NV、返回 quiet NaN（**f2i 例外**：饱和为整数 + NV）；`minmax` 例外（单 NaN 返回那个数，只置 NV）；`classify` 只分类不置标志；`sign`/`cs_rf` 逐位操作不置标志。
- `qNaN` 作算术输入 ⇒ 返回 qNaN（不置标志）；payload/符号策略见未决 4（默认：**算术族 canonical qNaN，符号 0**；`convert_ff` 按 spec **传播 payload**）。
- `0 × ±Inf` ⇒ NV+qNaN，且**优先于**加数 qNaN 传播（fma 同）；`Inf + (−Inf)`、`0/0`、`Inf/Inf`、`sqrt(负数非 −0)` ⇒ NV+qNaN。
- 精确和/积为 ±0 的符号按 IEEE754 §6.3：RDN ⇒ −0，其余 +0；`x + (−x)` ⇒ +0（RDN 下 −0）。
- `−0 < +0`（minmax）；`roundint` 结果为 0 时沿用输入符号（`trunc(-0.5) = -0`）；`rem` 结果符号随 x；`sqrt(−0) = −0`；转换保留零符号。
- Inf：`rem(x, ±Inf) = x`；`sclb(±Inf, n) = ±Inf`（n 不影响）；`sclb(±0, n) = ±0`；div 的 `±Inf/±Inf` ⇒ NV+qNaN。

### 各族补充细则

- **remainder**：商 `n` 用「最接近、平局取偶」；实现用有界整数 shift-subtract（不得引入大数库，也不得按 `|x/y|` 迭代 2^2000 次）；结果精确 ⇒ 无 NX/OF/UF。
- **scaleB**：指数相加用 `int64` 有符号饱和判断；`n` 超出可表示范围时直接判 OF（向 ±Inf + OF + NX）或 UF（tiny + UF/NX），**不得**按 `n` 迭代。
- **f2i**：饱和到目标宽度/符号性；NaN/Inf 亦饱和并置 NV；有限 inexact ⇒ NX；舍入方向见未决 1。
- **i2f**：`i*` 符号扩展、`u*` 零扩展后按整数→浮点精确舍入；只有 NX。
- **compare**：`−1` 为 64 位全 1（`0xFFFF_FFFF_FFFF_FFFF`），不得只写 32 位；`±0` 相等；unordered 判定用 NaN 分类，不依赖宿主比较。
- **classify**：10 位 one-hot；`±0` 与次正规、正规、Inf、q/sNaN 的判定按 IEEE 字段（`exp==0`/`exp==max`/尾数）。
- **roundint**：`|x| ≥ 2^p` 原样返回（p = 24/53）；**禁止**用「转整数再转回」实现（会丢大数与符号）；5 个静态档不得置 NX。
- **同格式搬移**（`ft2ft`/`fo2fo`）：位保真；仅 sNaN 输入会被 quiet 化并置 NV；`ft2ft` 仍只写低 32 位。

### 4) `B7Context : public B6Context`

```cpp
class B7Context : public B6Context
{
  public:
    ~B7Context() override = default;
    /** rf0[33:32]：0 RNE / 1 RTZ / 2 RDN / 3 RUP。 */
    uint8_t roundMode() { return uint8_t((readFloat(0) >> 32) & 0x3); }
    /** sticky-OR 本次 accrued 标志；无标志时不写 rf0。 */
    void accrueFlags(uint8_t f)
    {
        if (!f) return;
        writeFcsr(readFloat(0) | (uint64_t(f) & 0x1F));
    }
};
```

## 语义裁定（2026-11-02）

用户裁定：**B7 完全按 IEEE 754-2019；该标准未定义/未规定的细节才需再问用户**。据此：

1. **f2i 舍入方向**：按 IEEE 754-2019 `convertToInteger` 使用当前舍入方向；DADAO `rf0[33:32]` 提供该方向（RNE/RTZ/RDN/RUP），不固定 RTZ。
2. **f2i NaN/Inf/超范围**：DADAO `contract-fp §3` 明确为饱和；NaN 无符号性，模型取目标宽度最大值并置 NV；+Inf 取最大、−Inf 取最小；该饱和规则是 DADAO 明确口径，不冒充 IEEE 未定义行为。
3. **compare 标志**：按 IEEE 754-2019 的 quiet/signaling 比较；相关 invalid 置 NV（只置 `rf0[4:0]`，不触发 trap）。若实现发现 spec 与 754 字面冲突，停下报告。
4. **算术 NaN 结果**：按 IEEE 754-2019 返回 quiet NaN；未规定 payload 时用 canonical qNaN（符号 0、payload 0）；`convert_ff` 的 payload 传播按 spec 保留。
5. **unordered 比较位型**：DADAO spec 要求 qNaN/sNaN 且符号位 0；模型用 canonical 位型：ft qNaN `0x7FC00000`、sNaN `0x7F800001`；fo qNaN `0x7FF8000000000000`、sNaN `0x7FF0000000000001`。
6. **`rootn(-0,2)`**：spec 明确不作具体要求；模型取 `−0`，测试标 UNSPECIFIED，不声称 IEEE 要求。
7. **ft 高 32 位**：DADAO 寄存器模型选择保留高 32 位（与 B1 `ld.t` 一致），在 README/changelog 标注为模型选择。
8. **oracle 归属**：`tools/gem5/b7_ref.py` 留在 gem5 模块，仅只读复用 testcases 的位级原语。
9. **时序/StaticInst**：B7 只做值语义；FP 资源/延迟模型留待 SE/FS 接入任务。
