# m18-qemu-005: QEMU 异步模型修订（掩码归 monitor、源位图、cg9 七槽）

**模块**：qemu
**项目里程碑**：M18
**依赖**：`m18-spec-004`（ADR-0061 落地）合入；`m18-qemu-004` 已合入（在其实现上改）
**可并行分片**：否（同改 `components/qemu`）
**预估**：3–5 h
**档位**：大改（复核 ≤60 min）
**状态**：已验证

## 背景

`m18-qemu-004` 按 `ADR-0060` 实现（掩码在 `cfx_hart cg9 rc8–rc12`、pending/cause 位 = `1<<17`/`1<<18`、`cause_id` 单值、软件写 0 释放）。`ADR-0061` 改为：掩码归**运行模式 monitor**（`cfx0–3 cg8 rc1`，复位全 1、位 = 源 cfxha）、源身份统一 cfxha（去掉 17/18）、`cg9` 七槽且两个位图 HW/RO、同一界面的多源**一帧承载**、帧由 `escape` 结束。

## 要做

1. **掩码迁 monitor**：投递时按 `inner_run_mode` 取 `cfx{0..3}` 的 `cg8 rc1`（`cfx2rc`/`cfx2rd` 可读写，复位全 1）；删除 `cfx_hart cg9` 的五个掩码与 `saved_global_intr_mask`。
2. **源索引 = cfxha**：`src_pending` 位 `1<<15`/`1<<32`；帧内 `src_frame` 同索引；**删除** `DADAO_CAUSE_TIMER=1<<17`/`DADAO_CAUSE_PMEM_DMA=1<<18` 与 `dadao_cause_check` 的 `[31:16]` 放行（同步 cause 表里也不再出现 17/18）。
3. **`cg9` 七槽**：`rc0 prev_run_mode`/`rc1 prev_cfx`/`rc2 cause_ip`（= 边界 `env->pc`）/`rc3 src_frame`（RO）/`rc4 src_pending`（RO）/`rc5 excp_vector`/`rc6 switch_run_mode`；`rc7–15` ⇒ `CFXREG`；两个 RO 字段**写忽略、读回不变、不产生异常**。
4. **一帧多源**：同一 TB 边界把所有 `pending && !masked` 的源**合并**进一帧（`src_frame` 并集、`src_pending` 扣除、`excp_async_num` +1），不再"一个源一次调用、按 cfxha 串行"。
5. **pending 跟随源**：投递即清位；源 ack（`timer_cmp` 重装 / `dma_status` W1C）后 pending 落；无嵌套由 `src_frame != 0` 判。
6. **`escape` 不变**：保留 `imms18[1]` 与 `{0,1,2}`/`3⇒ILLI`；`cg9` 帧有效 = `src_frame != 0`；返回即清 `src_frame`。
7. **探针/文档**：`tools/testcases/arch/min_rom_probe_integ051t.py`、`tests/arch/vast-arch-inventory.md`、`tools/testcases/arch/README.md` 改新口径；旧 `094t`/`050t` 由 `m18-testcases-001` 负责（本任务只保证实现层一致）。
8. **不回归**：M16 cfx5/cache 代表集；`check-patch-tree` qemu 段 0 problem。

## 不做

- 不改 spec/契约（`m18-spec-004`）；
- 不改 LLVM/IDL（`escape` 不变）；
- 不改 RTL/kernel/gem5（各自修订任务）；
- 不升版本号。

## 约束

- 独立 `git worktree`；**不提交 git**；补丁按 `docs/Process-01` 导出，`make_patch.py qemu` 幂等；
- 不写运行期路径；术语"寄存器组"；失败路径短 timeout（ISS-522）。

## 验证

运行期证据目录内的 `run.sh`：

1. 三模式（U/J/S/H）各写自己 monitor 的掩码：屏蔽 ⇒ 只置 pending；放行 ⇒ 投递；
2. `src_pending`/`src_frame` 位 = `1<<15`/`1<<32`；`src_frame != 0` 时不嵌套；`escape` 后释放；
3. **同帧多源**：timer + DMA 同时 pending ⇒ 一次进入、并集、`excp_async_num` +1；对照"串行两帧"判红；
4. ack 语义：重装 `timer_cmp` / W1C `dma_status` ⇒ pending 落、无遗留投递；
5. **可达 FAIL ≥3 路**：① 掩码仍留 `cg9`；② pending 位记 17；③ 多源串行开两帧；`cp`+md5 还原 + 重建回绿；
6. `check-patch-tree` qemu 段 0 problem、`check-component-changelog`、`check-knowledge-refs` 记录 rc。
