# m17-idl-021: IDL 复核遗留清理（ISS-490 / ISS-491）

**模块**：idl
**项目里程碑**：M17
**依赖**：`m17-idl-020`（cfxreg/cfxexe 合入后才能验 `CFXPERM` 覆盖）
**可并行分片**：否
**预估**：1–2 h
**档位**：小改（复核 ≤20 min）
**状态**：已验证

## 背景

两条 P3 复核遗留（非阻断、当时随任务放行）：

- `ISS-490`：① `addr48_truncate` 自检是 Python 常量表达式（近乎恒真）；② 证据脚本把 self-test 期望写死 28；③ `Cfx.access()` 未实现 `cfxreg` → **已由 `m17-idl-020` 实现**（本任务只需验证覆盖）；④ `check-temp-dirs` 为他任务；
- `ISS-491`：① 运行期证据脚本 `probe_red` 只断言 rc；② trace 的 `id`/`mn` 两侧同源 `contracts/opcodes.yaml`（非独立证据）；③ `dst`/`val` 派生函数两侧共用（输入不同源，可接受）；④ `rd8_skip`/`ra_skip` 覆盖偏大，需在格式文档写覆盖率。

## 要做

1. `idl/tools/idl_exec.py` 自检：把 `addr48_truncate` 改为**可达**的真实断言（非常量折叠），或删除并保留 `addr48_zero_window_faults` 作为唯一覆盖；
2. `idl/tools/idl_check_trace.py` / `docs`/`idl/docs/trace-format.md`：写清 ②「`id`/`mn` 同源」与 ④「skip 覆盖率」两个限制；若 `probe_red` 仍在仓，补「输出含 `[FAIL]`」断言；
3. 验证 `CFXPERM` 覆盖：`m17-idl-020` 的两个载体在 IDL 上产生 `CFXPERM`（`cause_id=0x80`、`cause_info=指令地址`），把该证据写入完成区；
4. 关闭 `ISS-490`（①②③④逐条给处置）与 `ISS-491`（①②③④逐条给处置，②③④为文档/设计说明）。

## 不做

- 不改 020 的语义与载体；不改 003/004 的归档证据脚本（在运行期、不在仓）；
- 不扩大 trace 判据。

## 约束

- 独立 `git worktree`；不提交 git；只动 `idl/tools/idl_exec.py`、`idl/tools/idl_check_trace.py`（如需）、`idl/docs/trace-format.md`、本任务书；完成区 ≤30 行。

2. `make check-idl` 274/274；`check-idl-parse`/`sync` 绿；
3. 文档与实现一致（grep 关键句）；
4. `check-knowledge-refs` rc=0。
