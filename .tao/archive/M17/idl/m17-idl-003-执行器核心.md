# m17-idl-003: 执行器核心（四寄存器组 / ELF / 最小 trap）

**模块**：idl
**项目里程碑**：M17
**依赖**：`m17-idl-002`（解析器）
**可并行分片**：否
**预估**：3–4 天
**档位**：大改
**状态**：已验证

## 拆分说明（用户 2026-11-21）

原 5–7 天版本按「核心 / trace」拆成两件：本任务只做**执行器核心**；逐指令 trace、格式文档与 QEMU 逐指令比对归 `m17-idl-004`。

## 目标

1. 四寄存器组状态（`rd`/`rb`/`rf`/`ra`）、48 位地址、大端显存模型；
2. ELF 加载：复用 `tools/testcases/lib/machine_profile.py` 的运行布局，**不另造第二份机器真源**；
3. 取指/译码/执行最小闭环：算术 / 访存 / 控制流（`jump`/`call`/`br.*`）/ 寄存器搬移；
4. 最小 trap/monitor：`trap`/`escape` 按 `contract-see`，够跑 `tests/inst` 的同步异常例；
5. 跑通 ≥20 条代表 operation（算术 / 访存 / 控制流 / 异常各类都要有），断言**最终架构状态与退出码**与 QEMU 一致（逐指令 trace 归 004）。

## 验收（逐条贴真实 rc）

1. ≥20 例（`tests/inst` 已有载体，不新造向量）的**最终状态/退出码**与 QEMU 相等；
2. 自检：寄存器组初值/写回、地址 48 位截断、大端读写各有断言；
3. **可达 FAIL ≥2 路**：① 破坏一条算术宽度规则 ⇒ 结果例红；② 大端读改写小端 ⇒ 访存例红；
4. 门控：`check-idl-parse`、`check-idl-sync`、`check-knowledge-refs` 真实 rc。

## 约束

独立 `git worktree`；**不提交 git**；**不改 QEMU/gem5/RTL**；术语「寄存器组」；完成区 ≤30 行、不写运行期路径；状态 → `待验收`。

**验收结果**：

- 验收 3：注入 A（`add.st` 去掉 32 位截断/符号扩展）⇒ `add.st_orrr_rd` 红（退出码 2、字节 0/136）；注入 B（数据 `_read`/`_write` 的 `big`→`little`）⇒ `ld.o`/`st.o` 红；两路 `cp`+md5 还原后回绿且 md5 与注入前一致。

**新发现/坑**：
- QEMU `-d cpu` + one-insn-per-tb = 每条指令**执行前**状态；但会在部分 `br.nz` 处**重复一条**记录、且**不为取指异常**（IALIGN/CFXMEM fetch）出记录 ⇒ 004 逐指令比对须按 PC 对齐、不能逐行（实测 escape 例 QEMU 1160 记录 vs 执行器 295 条）。
- QEMU 对「无返回」semihosting 服务写 `rd8=0xdeadbeef`（`common_semi_dead_cb`），非架构语义 ⇒ 结果比对跳过未定义的 `rd8`。
- `ra1..ra63` 在 `RACNT` 有效区外**未定义**（`SimRISC-00 §2.4`）⇒ 只比有效区；`ra0` 全比（`ret_riii` 例）。
- Tiny BootROM 表头 `>IHHII`（magic/version/count/boot_magic/reserved）、表项 `>IIQQQ`（type/flags/offset/size/reserved）；hmon 段在镜像 `0x2000..0x4000`，复制到 hmon SRAM 起始（`spec/Kaiwu §6.2`）。
- `trap` 到**未实现** cfx ⇒ `ILLI`，`cfx2rd`/`cfx2rc` 到未实现 cfx ⇒ `CFXREG`；`CFXESC` 目标 = **当前 cfx**（不是 monitor）；`cause_info` 按 `DADAO-12 §4.1` 表（ILLI/UNDI/CFXREG/CFXESC=指令编码、CFXPERM=触发指令地址、MALIGN/CFXMEM=地址、RASOF=待压入返回地址）。
- QEMU 11 system 模式无 `-singlestep`，用 `-accel tcg,one-insn-per-tb=on`。
- 语义实现方式 = 按 `.idl` 正文**逐 id 手写**（不是通用 AST 求值器）：28 例实际执行 54 个 id；未注册 id 一律显式 `ExecError`（不静默成功）。
**遗留问题**：
1. 不是通用 IDL AST 求值器；`U04`–`U10` 宽度裁定仍未取——执行器不做宽度推导，靠 `opcodes.yaml` 字段位域 + 每 id 语义。
2. 54 个已执行 id 之外未注册（`add.ut`/`ld.t` 等模型不确定的一律显式失败）；004 扩例时按需补。
3. 未新增 Makefile 门控（差分需安装根 + QEMU；本任务未要求新门控），`--self-test` 也未接 L1。
4. `check-temp-dirs` 红（`m14-linux-017` 等**他任务**陈旧临时目录；只报告不删除，非本任务引入）。
